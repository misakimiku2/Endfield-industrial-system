# 04 · 传送带系统

> 上一篇：[03-核心框架与世界模型](03-核心框架与世界模型.md) ｜ 下一篇：[05-生产与端口系统](05-生产与端口系统.md)

传送带子系统由两部分组成：**创建交互**（BeltCreationSystem + 寻路 + 几何 + 对接）与**运行模拟**（BeltSystem），外加链管理（BeltChainOps）与选中状态（BeltSelection）。

## 1. 链模型（核心概念）

物理上每格传送带 = 1 Entity（`BeltSegmentComp` + `Position` + `SpriteComp`）；逻辑上一条链由以下隐式表达（**不使用** `BeltLinkComp`，它是预留件）：

- `chainId`：同一次创建/延长的段共享（`chain-<时间戳>-<计数>`；断链重拆分配 `chain-split-...`）；
- `segmentIndex`：链内连续序号 0..n；
- `isTail`：末段标记（可继续延长的断头）；
- **方向几何**：直段 `direction` = 流向；转角段 `entryDir` = 入方向、`direction` = 出方向。

链被约束为**简单路径**：无环、无分支，每段至多一进一出。

核心常量（`systems/BeltSystem.ts`）：

| 常量 | 值 | 含义 |
|---|---|---|
| `ITEM_PROGRESS_PER_TICK` | 0.025 | 每 Tick 推进量 = 0.5 格/秒 × 50ms；跨一格 40 Tick = 2 秒 |
| `MIN_ITEM_GAP` | 1.0 | 一格一物品的世界间距 |
| `STOP_MAX` | 0.5 | 断头/门口停走位置（格中心）；被 IntakeOps 复用为吸入判定点 |
| `PORT_ENTER_DONE` | 1.5 | 预约物品（entering）的推进上限（端口格中心），之后被 MachineSystem 移除 |
| `BeltSystem.beltPhase` | 0~1 | 全局流动相位，**仅驱动指针箭头动画**（2026-08-25 起与物品解耦） |

> ⚠️ 常量同源约束：`IntakeOps.PORT_ENTER_PROGRESS === BeltSystem.STOP_MAX`、`PORT_RELEASE_PROGRESS === BeltSystem.PORT_ENTER_DONE`，两边禁止各自定义（见 [09-依赖关系](09-依赖关系.md)）。

## 2. 创建交互 BeltCreationSystem.ts（1019 行）

维护"传送带创建模式"状态机：

```
idle --E键--> hover --左键选中起点--> preview --左键(逐段落盘,可多次)--> preview
preview/hover --右键/ESC/E--> idle（不落盘当前预览段；落盘只由左键负责）
```

起点两类（`findStarts()`）：**port**（设备的 `output` 端口格）与 **tail**（已有链的断头尾段）。禁止从输入端口起画（悬停输入口显示红色警示格 `getStartHintCell`）。

主要公有 API：

| 方法 | 说明 |
|---|---|
| `toggleMode() / enterMode() / exitMode() / isActive()` | 模式管理（E 键切换） |
| `setMouse(x, y, inside)` | preview 态鼠标移动立即 `refreshPreview()` |
| `onPointerDown(_, _, button)` | 右键退出；左键 hover 选起点 / preview 落盘 |
| `getHoveredPortCell() / getHoveredAnyPortCell()` | 渲染层端口高亮数据源 |
| `getDockInfo()` | 预览末段对接信息（确认对接 → 端口绿色高亮） |
| `getHiddenTailCell()` | 延长断头带时被预览接管隐藏的原尾格 |
| `getStartHintCell()` | 输入口起画红警示 |

预览刷新流程（`refreshPreview()`）：

1. **端口重定向**：鼠标停在输入端口格 → 寻路目标改为端口朝向侧的"供给格"，末段方向吸附为逆朝向（`BeltDockOps.dockRedirect`）——从任意方向拖到端口都能自动接入；
2. **寻路**：`findPath(lastAnchor, target, makeIsBlocked(), options)`——动量 L 形优先、BFS 绕障兜底；首段方向约束（tail 允许 90° 侧转但禁 180° 折返；后续段动量延续禁逆流）；
3. **合法性判定** `checkPathValid`：越界/占用/绕回起点 → 预览整条染红（无效 0xe45050）/ 蓝（有效 0x76bbea）。

落盘（左键 `addWaypoint()` → `commitCells()`）：

- 首次落盘定 `chainId`：tail 起点继承原链 id、原尾段降级 `isTail=false`、新段 segmentIndex 接续；port 起点新建链。
- 逐格创建实体：`Position` + `SpriteComp`（直段 `transport_belt` / 转角 `belt_corner`）+ `BeltSegmentComp`（含 `phaseOffset: Math.random()`）+ `occupancy.occupy(gx, gy, 'transport_belt')`。
- 旧尾格按新拓扑重算直段↔转角（`updateSegment`），保证跨段转角正确。
- 特殊情形 `commitTailResnap()`：尾格已在供给格但方向不对时，直接把已落盘尾段转向端口。

## 3. 寻路 BeltPathfinding.ts（337 行）

**双层启发式**，无 A*、无加权代价：

1. `calculateMomentumPath`：动量 L 形（先沿惯性方向迈一步再走 L），O(路径长)，零搜索；
2. `findPathBFS`：4 向网格 BFS（均一代价 = 曼哈顿最短路），搜索上限 `MAX_SEARCH = 5000`；**非起点节点禁止 180° 反向**（只展开直行与两个 90° 转向——符合传送带流动特性）；
3. 全部失败 → `calculateMomentumPath` 理想路径整条染红提示。

约束注入：`IsBlocked = (cell) => boolean` 闭包由 BeltCreationSystem 提供——设备与已放置传送带的占用格阻挡（`occupancy.isOccupied`）、已确认路径格阻挡（防自交）、`lastAnchor` 豁免、port 起点的端口格豁免（tail 起点不豁免——防穿回原链造成重叠段）。终点格被占用不算寻路失败（仍生成路径供红色警示）。

导出：`findPath / calculateMomentumPath / findPathBFS / deduplicatePath / directionBetween / keyOf` 等。

## 4. 路径几何 BeltPathGeometry.ts（228 行）

纯函数几何数学，"预览 ↔ 落盘 ↔ 渲染"三方共用（改这里要三处联测）：

| 导出 | 用途 |
|---|---|
| `directionVector(dir)` | 0=右(+x)、90=下(+y)、180=左、270=上 |
| `directionAngle(dir)` | 屏幕系角度（y 向下） |
| `getCellTurnInfo(path, index, ...)` | 按路径索引推导 `{isTurn, incomingDir, outgoingDir, isCCW}`（单格/首格/尾格/中间格四分支） |
| `turnInfoFromDirections(in, out)` | 无需路径上下文的转角判定；`isCCW = (outIdx − inIdx + 4) % 4 === 3` |
| `beltTextureRotation(dir)` | 直段纹理旋转（素材默认朝下：down→0、right→π/2、up→π、left→−π/2） |
| `beltCornerTransform(entry, exit)` | 转角渲染变换：CW = `rotation = angle(exit)` 不镜像；CCW = 转 (outAngle−π) + **水平镜像** |

## 5. 运行模拟 BeltSystem.ts（384 行）

每 Tick（dt 恒 50ms）三阶段：

### ① 物品推进（反向遍历）

`world.query('BeltSegmentComp','Position')` 从**链尾向链头**遍历——下游段先处理，使跨段 push 的新物品本 Tick 不再推进（渲染无顿挫），且上游读到下游本 Tick 最新位置 → 整链 lockstep。

`processSegment`（段内按 progress 降序，队首 = max progress）四分支：

| 队首情形 | 处理 |
|---|---|
| `entering`（已预约进设备） | 推进到 `min(+0.025, 1.5)`，不参与跨段/钳制；到 1.5 由 MachineSystem 同 Tick 移除 |
| 无下游段（断头/门口未预约） | 钳制在 `STOP_MAX = 0.5`（格中心） |
| 到段尾（≥1.0）且下游无有效物品 | **跨段**：push 到下游段首（progress=0），本段移除；`entering` 物品不计入下游阻挡（预约物品是设备所有的过客，后件到段尾即跟进） |
| 其余 | `stopAt = min(自身推进, 下游最小位置 − 1.0, 1.0)`，且不后退 |

后方物品按 `队首位置 − MIN_ITEM_GAP` 钳制（不后退）。每件物品写 `delta = 本Tick增量`（0 = 停走，渲染静止）。

### ② 全局相位

`beltPhase = (beltPhase + 0.025) % 1.0`——仅作指针动画时间源。

### ③ 链级堵塞分类（`seg.blocked`）

两段式：

1. **rawStopped**：链内任一物品 `delta === 0` → 该链候选；
2. **classify 递归**（深度 >16 环防御）区分"真堵（红）"与"轮询等待（不红）"：
   - 链尾无 dock、或侧向横穿指入端口 → **断头红**；
   - `comp.paused` 或仓库存货口（无限汇）→ 不红；
   - 门口物品可收（槽有空位/同类未满）→ 不红（本 Tick 即将吸入的瞬态）；
   - 槽满但类型不符 → **类型不符红**；槽满且 `state !== 'working'` → **槽满停产红**；working（正在消耗）→ 不红。

最终 `seg.blocked = rawStopped && 真堵`，渲染层据此把带身黄带染红（渐变 250ms）、箭头染 `#E6956F`。

## 6. 链管理 BeltChainOps.ts（206 行）

| 函数 | 语义 |
|---|---|
| `queryChain(world, chainId)` | 全表扫出该链全部段（顺序任意） |
| `deleteChain(world, occupancy, chainId)` | 销毁整链 + 释放占用，返回删除段数 |
| `deleteSegment(world, occupancy, handle)` | **删单段 + 断链重拆**：按无向连通分量（前驱/后继双向 DFS，基于空间方向几何 `topologyOf`，不依赖 segmentIndex）把剩余段分成若干分量；含原链头的分量保留原 chainId（上游），其余分配 `chain-split-...` 新 id；每分量重写 segmentIndex 0..n 与 isTail |

## 7. 终点对接 BeltDockOps.ts（108 行）

纯逻辑（不依赖 World/渲染，可单测）。统一口径：**供给格 = 端口格 + directionVector(outward)，段从朝向侧指入**。

| 函数 | 语义 |
|---|---|
| `dockRedirect(mouseGrid, ports)` | 鼠标悬停输入端口格 → 寻路目标重定向到供给格 + 末段方向吸附（`DockSnap`） |
| `applySnapToCells(cells, snap)` | 把吸附方向写到末格（会产生 180° 折返时不覆盖） |
| `dockInfoOf(tail, tailDir, ports)` | 末段出口命中端口格且末格在朝向侧 → `confirmed`（渲染绿色"将连接"） |

运行期对接在 MachineSystem 侧（`IntakeOps.findFeederBelt` / `OutputOps.findReceiverBelt`），与放置期同口径——见 [05-生产与端口系统](05-生产与端口系统.md)。带→带无显式对接：`BeltSystem.findDownstream` 按方向向量找位置匹配的相邻段（<1px 容差）。

## 8. 选中状态 BeltSelection.ts（50 行）

## 9. 相关渲染器（细节见 [07-渲染与UI](07-渲染与UI.md)）

- `BeltVectorRenderer`：矢量带身（Graphics），读 `direction/entryDir/mirrorH`，按选中 > 堵塞 > 创建模式渐变染色；
- `BeltPointerRenderer`：黄色指针箭头流动，相位 = 链领头物品位置跟随（队列停箭头停；空带回退全局相位）；
- `BeltItemRenderer`：物品按 `progress` + `delta` + `alpha` 帧间内插，转角走圆弧；
- `BeltHoverRenderer`：悬停带格的呼吸四角框；
- 端口半格残段：物品在 [-0.5, 0) 与 (1.0, 1.5] 区间"钻入设备"的带身。
