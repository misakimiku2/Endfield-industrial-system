# 11 · 关键类与函数速查

> 上一篇：[10-运行与构建](10-运行与构建.md) ｜ 下一篇：[12-文件清单](12-文件清单.md) ｜ 返回：[README](README.md)

按模块分组的关键 API 速查表。签名从简，完整语义见对应专题文档。

## ECS（src/game/ECS.ts）

| API | 签名 | 说明 |
|---|---|---|
| `World` | `class` | ECS 核心，零依赖 |
| `World.createEntity` | `(): EntityHandle` | 创建实体（generation-based 句柄） |
| `World.destroyEntity` | `(handle): void` | 幂等销毁；代数+1 使旧句柄失效；不清 PixiJS 对象 |
| `World.isAlive` | `(handle): boolean` | 越界/存活位/代数三重校验 |
| `World.addComponent` | `<T>(handle, key: string, data: T): void` | 组件=纯数据；同 key 覆盖 |
| `World.getComponent` | `<T>(handle, key): T \| undefined` | **返回对象引用**，直接 mutate 生效 |
| `World.hasComponent / removeComponent` | `(handle, key): boolean / void` | |
| `World.query` | `(...keys: string[]): EntityHandle[]` | 拥有全部 key 的存活实体数组 |
| `EntityHandle` | `type = number` | 编码 `(generation << 20) \| index` |

## 编排（Game.ts / GameLoop.ts / main.ts）

| API | 签名 | 说明 |
|---|---|---|
| `Game` | `class` | 组合根：world/worldData/camera/renderSystem/occupancy/placement/beltCreation/gameLoop/beltSystem |
| `Game.tickSimulation` | `(deltaMS): void` | 仿真 Tick（必须先于渲染 update） |
| `Game.initProduction` | `(recipes, items): MachineSystem` | 幂等；注册 MachineSystem（BeltSystem 之后） |
| `Game.update` | `(deltaMS?): void` | 渲染同步，内部算 alpha 插值系数 |
| `GameLoop.addSystem` | `(sys: SimulationSystem): void` | 注册顺序 = Tick 内执行顺序 |
| `GameLoop.update` | `(frameDeltaMS): void` | 累积器 → while 固定 50ms Tick |
| `GameLoop.accumulator` | `get: number` | 0~50ms，渲染插值系数来源 |
| `SimulationSystem` | `interface { update(world, dt): void }` | dt 恒 50ms |

## 世界（world/）

| API | 签名 | 说明 |
|---|---|---|
| `MapInstance` | `class` | 地图尺寸唯一真相源（widthCells/heightCells/widthPx/heightPx） |
| `createDefaultMap` | `(): MapInstance` | 64×64 Cell |
| `WorldData` | `class { map }` | 世界静态数据容器（非 ECS World） |
| `OccupancyMap.canPlace` | `(gx, gy, w, h): boolean` | footprint 左上角语义；边界+逐格占用 |
| `OccupancyMap.occupy / release` | `(gx, gy, defId?)` | 单格占用/释放（幂等） |
| `OccupancyMap.occupyFootprint / releaseFootprint` | `(gx, gy, def, direction)` | 按 `effectiveFootprint` 整片占用/释放，方向敏感 |
| `OccupancyMap.isOccupied / getOccupant / snapshot` | | 查询 |

| `formatRecipeSummary` | `(recipe, nameOf): string` | 摘要文本 |

## 传送带（systems/BeltSystem + belt/）

| API | 签名 | 说明 |
|---|---|---|

| `MIN_ITEM_GAP / STOP_MAX / PORT_ENTER_DONE` | `const 1.0 / 0.5 / 1.5` | 间距 / 停走点 / 预约放行点（**常量同源约束**） |
| `BeltCreationSystem` | `class` | 创建模式状态机 idle/hover/preview |
| `.toggleMode / enterMode / exitMode / isActive` | | 模式管理 |
| `.setMouse / onPointerDown / onKeyDown / update` | | 输入入口（main.ts 转发） |
| `.getHoveredPortCell / getDockInfo / getStartHintCell / getHiddenTailCell` | | 渲染高亮数据源 |
| `findPath` | `(start, end, isBlocked, opts?): GridCell[] \| null` | 动量 L 形优先 + BFS 兜底 |
| `findPathBFS` | 同上 | 禁 180° 反向；上限 5000 节点 |
| `getCellTurnInfo / turnInfoFromDirections` | `(...): CellTurnInfo` | 转角判定 `{isTurn, in, out, isCCW}` |
| `beltTextureRotation / beltCornerTransform` | `(dir) / (entry, exit): CornerTransform` | 直段旋转 / 转角 CW-CCW 变换（预览↔落盘↔渲染共用） |
| `queryChain` | `(world, chainId): EntityHandle[]` | 链查询 |
| `deleteChain` | `(world, occupancy, chainId): number` | 整链删除 |
| `deleteSegment` | `(world, occupancy, handle): void` | 单段删除 + 无向连通分量断链重拆 |
| `dockRedirect / applySnapToCells / dockInfoOf` | | 终点吸附与对接确认（BeltDockOps） |
| `BeltSelection` | `class` | 选中态共享对象：set/has/toggle/clear/getHandles |

| `PortStatusOps.portStatuses` | `(world, handle, comp, def): {input, output}` | 端口 connected/blocked 只读判定（渲染+调试同源） |
| `PortGeometry.inputPortCells / rotatePort / portOutwardBase / rotateDirection` | | **端口几何单一事实源** |
