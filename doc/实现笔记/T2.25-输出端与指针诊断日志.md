## 日志通道（全部走 logisticsDebug 单例，控制台 + `__game.logisticsLog()` 覆盘）

### 仿真侧 — MachineSystem（输出端，与 intake ⏳ 门口等待对偶）

- `📤 输出注入`（每次成功出货一条）:
  `📤 输出注入: 精炼炉(5,5)口1 → chain-…-A 首格(5,4) 晶体外壳 @槽位0.400/Δ0.025 | 领头 2.400【离格链 frac=0.400】 | 链上: seg1@0.975 seg2@0.400`
  - 槽位/Δ = 注入放置（T2.24）；领头 = 链领头 total；**离格链 frac≠0 标记**；
    链上 = 全链物品快照（`chainSnapshot`/`formatChainItems`，entering 加 E 后缀）。
  - 分析口径: 同链相邻两次注入的"链上"快照直接可读间距是否整数格；渲染端
    ⚠/❗ 日志与本行 chainId 对时序。
- `⏳ 输出等待`（节拍已到但走访一轮无一可写带 = 全场满带；按设备节流 800ms）:
  `⏳ 输出等待: 精炼炉(5,5) 节拍已到但无可写带（候选 2: chain-…-A×1 chain-…-B×2）— 货留输出槽`
- 取货口路径同口径（`📤 取货口出货` 扩展槽位/领头/链上字段）。

### 渲染侧 — BeltPointerRenderer（指针闪烁取证，每帧检测、节流防刷屏）

- `❗ 指针跳变`: 每帧每段相位增量超出 `[0, 帧流动×1.15+0.002]`（判定口径与
  scripts/diagnose-pointer-flicker.ts 一致）——**缺陷信号**，正常应恒为 0 条。
- `⚠ 物品离格`: Tick 边界帧检查链内每件物品对领头的 mod 1 距离 >0.005 格
  （每件只报首次，WeakSet 去重）——网格注入下在网物品应恒为 0，非 0 即
  "箭头与该物品错开"的直接根源（跨链衔接/离格旧物/异常注入）。
- `▴ 空链首件注入（接受类）` / `▾ 链清空 → 箭头转入空链自流`: 链空↔非空转换
  事件——感知闪烁的候选时刻，与注入/吸收日志对时序。

### 渲染侧 — BeltItemRenderer（物品闪烁取证）

- `❗ 物品跳动`: 帧间渲染位置后退 >0.004 或前进 >0.03（prev→cur 内插约定下
  合法帧增量 = [0, 0.025]±余量；注入/跨段首帧不参与）——按格节流。

### 支撑改动

- `LogisticsDebug.logThrottled(key, msg, minIntervalMs=800)`: 按键节流（渲染侧
  检测器每帧运行，持续异常必须节流否则淹没环形缓冲）；`enable(true)` 清节流表。
- `OutputOps.chainLeaderTotal` → `chainSnapshot`（leader + 全链物品一次扫描，
  供放置决策与注入日志；`formatChainItems` 摘要）。
- 关闭日志时渲染检测器零日志且重开清基准（`diagStale`），不产生跨时段误报。

## 用户侧使用指引（下一步分析）

1. 浏览器复现闪烁（物流日志默认开着）。
2. 看控制台/`__game.logisticsLog(200)`:
   - 有 `❗ 指针跳变` → 相位不连续（记录 格/链/前后相位/帧流动，对照同时刻
     `📤 输出注入`/`⏹ 物品停止`/`▴ 首件` 的时序）；
   - 有 `⚠ 物品离格` → 该物品/链条上存在非整数间距（对照注入日志的链上快照
     定位是哪一次注入/跨链产生的）;
   - 有 `❗ 物品跳动` → 物品渲染层问题（帧增量/alpha 一并截取）;
   - 全部为 0 但仍"看到闪烁" → 闪烁来自 ▴/▾ 转换时刻或渲染表现层（截图 +
     时间戳给我）。
