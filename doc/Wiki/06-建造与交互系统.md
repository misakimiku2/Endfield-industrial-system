# 06 · 建造与交互系统

> 上一篇：[05-生产与端口系统](05-生产与端口系统.md) ｜ 下一篇：[07-渲染与UI](07-渲染与UI.md)

本文覆盖设备放置（PlacementSystem）、旋转策略（RotationPolicy）、选中（SelectionSystem）、删除（DeleteSystem + 传送带删除）。传送带创建交互在 [04-传送带系统](04-传送带系统.md)。

## 1. PlacementSystem.ts（511 行）——设备放置

状态机 `mode: 'idle' | 'placing'`：

```
工具栏选中设备 → enterMode(def)   （同设备再点 = toggle 关闭；不同设备 = 切换并 screenAngle 归零）
R 裸按        → screenAngle = (screenAngle + 90) % 360   （四档循环）
左键          → tryCommit()（canPlace 失败直接 return；成功落盘并保持 placing 可连放）
右键 / Escape → exitMode()
```

输入全部由 main.ts 转发（`setMouse / onPointerDown / onKeyDown / update`），System 自身不监听 DOM。

### 旋转逻辑（核心防错设计）

- 按 R 永远只加**屏幕角度** `screenAngle`（`RotationPolicy.nextScreenAngle`），绝不直接对世界朝向 +90；
- 世界朝向换算：`direction = ((screenAngle − camera.viewRotation) % 360 + 360) % 360`——预览渲染与落盘 `BuildingComp.direction` 共用同一角度，**所见即所存**；
- 预览内容恒按 0° 尺寸绘制、以**有效占地中心**为锚整体旋转；`effectiveFootprint` 在 90°/270° 时宽高互换（3×1↔1×3，Factorio 惯例，四档全开放）；
- billboard 徽标反向旋转保持屏幕朝上。

### 预览渲染双路径

| baseStyle | 方案 |
|---|---|
| `whole`（缺省） | Sprite + `PreviewTintFilter`（主体染蓝/红 + 箭头 mask 精确变白） |
| `nineslice` | Container[九宫格底座 + 端口切片（`portMaskFromDef`）+ equipment 帧]，染色走逐 Sprite tint |

透明度 0.7；有效 `0x76bbea` / 无效 `0xe45050`；zIndex 10000 浮于已放置设备上。

### 合法性校验与网格吸附

- **鼠标位置 = 设备中心**：`topLeftGrid = round((mouseWorld − footprintPx/2) / CELL_SIZE)`，再**从 grid 派生 world**（同一舍入函数——修复"预览画 A 检查 B"错位；round 而非 floor——修复设备系统性偏左上）；
- 校验 = `occupancy.canPlace(gx, gy, effW, effH)`（仅占位 + 边界；端口连接合法性在传送带创建侧判定）。

### 落盘 tryCommit()

创建实体并添加：`Position`（左上角世界像素）、`BuildingComp`（direction/state='idle'/bufferInput/bufferOutput/inputPollIndex=0/outputPollQueue/currentRecipeId=null）、`SpriteComp`（恒 0° 尺寸，layer 2）；最后 `occupancy.occupyFootprint(...)`。

## 2. RotationPolicy.ts（18 行）

`type ScreenAngle = 0 | 90 | 180 | 270`；`nextScreenAngle(current) = (current + 90) % 360`。T2.17 起非正方形设备不再限制两档（配合 `effectiveFootprint` 宽高互换）。

## 3. SelectionSystem.ts（450 行）——选中交互

### 命中测试（模块级纯函数）

| 函数 | 语义 |
|---|---|
| `pickBuildingAt(world, wx, wy)` | 遍历设备实体，世界 AABB 点包含（宽高按 `effectiveFootprint`）；尊重 `def.selectable` |
| `pickBeltSegmentAt(world, wx, wy)` | 1×1 格 AABB（设备格与传送带格互斥） |
| `pickTargetAt(world, wx, wy)` | 先设备后带；注意 `EntityHandle` 可能为 0，必须 `!== null` 判空（历史 bug） |
| `buildingScreenPolygon(camera, handle)` | footprint 四角投影到屏幕（选中框顶点） |

### 交互流程（pointerdown/up 结构，为 T2.14 长按移动设备预留）

- pointerdown 只记录 `{target, time, mods}`，不提交；
- pointerup 短按（< 300ms）才提交：
  - **点空白**：无修饰键清选；Ctrl/Shift 保留；
  - **点传送带**：Shift = 选同链闭区间（anchor→target，按 segmentIndex 升序）；Ctrl = toggle 单段；普通单击 = 单格；同段 350ms 内二次单击 = **升级整链**（`queryChain`）；
  - **点设备**：清带选中，设为当前选中。
- 每帧 `update()`：设备选中画屏幕空间黄框（alpha 0.25 + 白描边，线宽随 zoom）；带选中不画屏幕框（视觉移交带渲染器）；目标被销毁自动清选。

### 对外查询

`getSelected()`（设备句柄）、`getSelectedChain()`、`clearSelection()`、`getBoxTopLeft()`。

**设备信息面板现状**：目前只有 T2.9b 临时件 `ui/DeviceReadout.ts` 的 `deviceReadoutText(comp, def)`（`"输入: x/cap　输出: y/cap"` 单行，4Hz 节流）。完整设备弹窗（电源开关/配方切换/进度条）规划为 T2.15，未落地；配方当前由 `findMatchingRecipe` 按 CSV 列表序自动匹配。

## 4. 删除

### 设备删除 DeleteSystem.ts（66 行）

`deleteBuilding(handle): boolean`——校验（null/已销毁/无 BuildingComp/未知 definitionId → false 无副作用）→ `occupancy.releaseFootprint(gx, gy, def, direction)`（幂等）→ `world.destroyEntity(handle)`（RenderSystem 下帧 diff 自动移除 Sprite）。选中态清空由 main.ts 调用。

### 传送带删除（不在 DeleteSystem）

在 main.ts 的 Delete 键分发（`src/main.ts:282`）+ `BeltChainOps`：

- 多选带段 → 逐个 `deleteSegment(world, occupancy, h)`（下游自动重拆为断头链）；
- 整链选中 → `deleteChain`；
- 删除统一走 Delete 键；右键语义专留"取消放置"。

**设备删除与传送带联动**：无显式断开逻辑——设备删除后占用释放，MachineSystem 下一 Tick 的 `findFeederBelt/findReceiverBelt` 自然查不到带，端口自动变为未连接。

## 5. 系统间关系

```
main.ts（输入转发 + Delete 分发）
  ├─ PlacementSystem ←→ OccupancyMap（canPlace/occupyFootprint）
  ├─ SelectionSystem → BeltSelection（共享选中态）→ BeltChainOps.queryChain（双击选链）
  ├─ DeleteSystem（仅设备） / BeltChainOps.deleteChain|deleteSegment（仅带）
  └─ PlacementSystem 与 BeltCreationSystem 互斥（进入一方先退出另一方）
```

PlacementSystem 与传送带模块**零直接依赖**：耦合仅通过共享 `OccupancyMap` 中立（设备放不下=格被带占；带画不进=格被设备占）。
