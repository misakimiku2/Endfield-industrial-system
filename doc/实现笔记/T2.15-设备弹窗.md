## 形态决策: DOM overlay（任务卡允许 DOM/Pixi 二选一）

- 弹窗根节点是 **canvas 的兄弟 DOM**（挂在 `document.body`，fixed 全屏 = 遮罩 + 面板）。点击弹窗/遮罩根本不会落到
  `app.canvas` 的原生监听上，**事件隔离天然成立**——与工具栏的「包围盒排除」方案（main.ts onPointerDownMain 先例）不同，
  无需任何坐标判断。window 上的 `pointerup` 虽会收到，但 SelectionSystem 无 pendingPress，天然 no-op。
- 图标**零新增美术资产**: ui/devices/items 三张图集的帧经 CSS sprite（`background-position` 负偏移 + 统一 scale 的
  `background-size`）直接引用；需要染色的白色图标（状态 X、标签页图标）走 **CSS mask**（mask 定位帧 + `background-color`
  上色，等价旧项目 SvgPicture colorFilter srcIn）。物品格的渐变底/等级色条按旧项目 `synthesis_grid._getGridSvg`
  的 SVG 字符串 1:1 生成 data URI。弹窗背景水印 `endfield-industries.svg` 从旧项目复制到 `public/window/`（2% 白、
  距顶 80/距左 740/800px，img 用 `filter: brightness(0) invert(1)` 转白）。
- 图集 JSON 懒加载缓存（构造即 `fetch` 预取三份 JSON，只取 frames/meta.size，与 Pixi 的 Assets 加载互不干扰）；
  图集迟到时 refresh 自动补刷。

## 文件与接线

- **`src/game/ui/DeviceDialog.ts` + `DeviceDialog.css`**: 弹窗全部实现。100ms 局部定时器刷新（旧项目
  building_synthesis_panel 同款节奏），只改文本/样式/类名——**带 CSS 动画的节点（指示器箭头/三角）只在开面板时构建一次**，
  刷新仅切 display（每 100ms 重建会让 animation 重置，箭头会僵死在起始透明度）；配方行只在配方 id 变化时重建。
- **选中即弹窗（双向绑定）**: main.ts 每帧 `deviceDialog.syncSelection(selection.getSelected())`（内部是单次比较的 no-op）。
  点设备 → 打开/切换；点空白/ESC/关闭按钮/遮罩 → 关闭（关闭按钮与遮罩走 `closeByUser()` → 回调 main 清选中；ESC 由键盘
  gate 直接处理）。**放置点击与传送带模式点击不经选中系统，不会误弹**（浏览器验收断言了这一点）。
- **模态键盘 gate**（main.ts，capture 相位 `stopImmediatePropagation`）: 弹窗开着时吞掉全部游戏快捷键（E/R/Delete/WASD…），
  仅放行 ESC = 关闭弹窗。**keyup 不拦**——按住 W 开弹窗再松开，keyup 必须到达 CameraController 清键态。
- **相机输入门控（本次踩坑的核心修复）**: CameraController 的 `mousemove` 挂在 **window** 上，DOM 遮罩挡不住——实测
  「点遮罩关弹窗（光标停在屏幕角）→ 视口被边缘滚动拖走 ~360px，后续点击全部落空」。新增
  `CameraController.setInputEnabled(bool)`，**只冻结边缘滚动这一条受 window mousemove 驱动的路径**（鼠标坐标照常跟踪，
  恢复后无需任何同步）；main.ts 在 ticker 里检测弹窗开→关翻转时同步调用。中键拖拽/滚轮监听在 canvas 上被遮罩天然挡住，
  WASD 被键盘 gate 拦截，均无需处理。
- **`__game.deviceDialog`** 暴露（`isOpen()`/`getHandle()`）；程序化开弹窗走既有 `__game.selectFirstBuilding()` 即可。
