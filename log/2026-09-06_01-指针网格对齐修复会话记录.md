## 六、后续轮 3: 两段视频逐帧分析 → T2.27 连续箭头流（渲染架构重写）

用户复测仍闪烁，提供两段无镜头移动视频（1.mp4 2-6s / 2.mp4 4s 起）+ 新日志
（localhost-1788686065358.log）。新日志 ❗/⚠ **全零**（T2.26 生效）——
**闪烁不是相位跳变，检测器对 mod 1 回卷盲视**（相位差 (0.975→0.0) mod 1 =
0.025 = 合法帧流动量）。方法论（详见 `doc/实现笔记/T2.27-连续箭头流.md）:

- **ffmpeg 抽帧 + 逐帧差分**: 全帧差分被镜头平移淹没 → 分离"相机运动帧"与
  "静止帧"; 60fps 胶片条（tile 拼图）逐帧目视。
- **根因（架构性）**: 旧模型"每格一枚精灵、相位 = (virt − segIdx) mod 1"在每个
  整点回卷——全体箭头向下瞬移 ~0.975 格（≈47px）。满载带上回卷点被物品盖住
  （无缝、潜伏）; **T2.21 稀疏出货后物品之间空格的回卷裸露** = 每 2 秒一次可见
  闪烁。2.mp4"物品上的闪烁" = 物品尾部 0.975 相位处的箭头贴着物品后缘随回卷
  消失/重现。T2.24/T2.26 修的是"落点"层面，回卷是架构性的。

**T2.27 实现**:

- **`BeltArrowStream.ts`（新，纯逻辑）**: `computeArrowPositions(chainLen, virt)` —
  箭头槽位 = {virt − m : m ∈ ℤ} ∩ 窗口[−0.125, chainLen+0.125]，升序。窗口边缘
  补入/裁掉 = 循环（两端被设备 sprite/端点遮挡），**链中段箭头位置帧间连续，
  结构性无回卷**。
- **`BeltPointerPhase.ts`**: `computeChainVirts()` 替代 `computePhases()`——领头
  {interp, tick} 双量; 积分 = 内插帧增量**不钳位**（吸收负增量 = 槽位集合整数
  平移，集合不变、精灵不可区分）+ 换领头帧改用 **Tick 总量差**（精确整数格，
  零漂移——内插差会把采样 α 相位差 ≈0.016 永久计入，900 Tick 漂移 0.13 格，
  实测复现后消除）+ 负增量帧分数校准（对齐新领头 Tick 位置）。
- **`BeltPointerRenderer.ts` 重写**: 每链箭头池 **Map<m, ArrowEntry>（按槽位序号
  键控——按数组下标键控会在窗口滑动时 reintroduce 瞬移）**; 链几何行走（段游标
  缓存; 直段**匀速**线性——旧端点扩展 moveRange 会破坏流匀速性，移除; 转角圆弧）;
  per-cell 单元蒙版退役; 保留堵塞 tint/选中白箭头/延长预览隐藏。
- **指针层 z-order（关键）**: 指针层移入 layer2Building zIndex 0.4（带身 0 之上、
  物品 belowItems 0.5 之下、设备 1 之下）——**"有物品隐藏箭头"硬切规则退役**，
  箭头从物品/设备下方连续滑过（2.mp4"物品上的闪烁"根源消除）。
- **空链注入落自流箭头相位**: slotPlacement 空链分支 = frac(beltPhase +
  chainPhaseOf(chainId))（`chainPhaseOf` 移交 OutputOps 单一来源，渲染侧播种同
  公式）——空链首件恰好落在自流箭头上，**消除 ▴ 再对齐闪跳**（1.mp4 2-6s）。
  downMin 防御钳两条分支一致（空链分支此前漏钳——注入相位越过下游钳位时配合
  不后退规则把物品永久卡在钳位外、破坏队列间距，t27 5d 暴露后修复）。

**验证**:

- **世界坐标连续性检测器（新增，先红后绿）**: 旧模型 **47 次回卷瞬移（红）** →

## 七、教训（累计）

- **撤销必须逐文件核对终态**（T2.24 轮）。
- **对齐问题优先在注入源头解决**（T2.24 轮）。
- **mod 1 相位检测对回卷盲视——周期性系统的连续性必须用世界坐标判定**
  （T2.27 轮; 相位差 (0.975→0.0) mod 1 = 0.025 = 合法帧流动量，旧检测器绿灯下
  47px 瞬移潜伏了一整轮）。
- **逐帧差分必须分离相机运动**（T2.27 轮: 全帧差分的尖峰大半是镜头平移;
  黄色带掩码 + 相机运动指标双门限才定位到真闪烁）。
- **恒定 α 采样陷阱复发**（T2.27 轮）: 诊断驱动内插时钟必须模拟真实的 α
  上升-回卷序列（T2.22b 笔记已记录，本轮又踩一次——每 Tick 三帧 α=0.25/0.6/0.9）。
- **积分器钳位在连续流下=每次事件丢失一份流动量**（T2.27 轮）: max(0,·) 钳位
  在硬切换模型里防回跳，在连续流模型里制造累积漂移——模型换架构时，旧防御
  要重新评估。
- **新分支必须继承旧分支的全部防御**（T2.27 轮）: slotPlacement 空链分支漏掉
  downMin 钳，注入越过下游钳位 + 不后退规则 = 物品永久卡在钳位外。

## 九、后续轮 4: 浏览器复测致命回归修复（T2.27-a，同日）

用户编译运行后报告三大症状: 指针动画消失、箭头被"链接成一条实心线"、帧率极低

**浏览器实测复现**（dev server + 程序化场景: 精炼炉 + 12 格输出带 + 取货口供料带）:
FPS 48、`beltPointers` 容器精灵 **147,390 个**（应为 ~36）——四个症状同源:

1. **根因（一行装配丢失）**: T2.27 重写 `BeltPointerRenderer.update()` 时，
   每帧分组建在局部 `grouped` Map（全新空箭头池），**从未 `this.chains.set()`
   存回持久字段** → 池同步每帧全量建精灵、窗口滑出销毁分支永不命中 →
   **每帧泄漏 (链长+1)×2 个精灵**（~55fps × 75s ≈ 14.7 万）。
2. **视觉"连成一条线"**: 泄漏的历史帧箭头仍挂在层上但无人更新，相邻帧箭头
   间距 = 每帧带速位移（~0.5px）→ 亚像素密铺整条带 = 实心黄带。
3. **帧率崩塌**: 14.7 万子节点每帧 sortableChildren 重排 + 位置/tint 重写。
4. **物品跳动日志刷屏**: 帧耗时拉长跨 1.6 Tick → 渲染帧增量 0.04 > 合法 0.025
   → T2.25 检测器每帧命中（检测器工作正常，报的是真实卡顿）。

**修复**: 分组循环改从 `this.chains` 取运行时、缺失才新建并立即存回；
`rt.segs` 每帧清空重填；箭头池/blockedBlend 跨帧存活（附带修正堵塞 tint 渐变
此前被每帧重建卡死在 0 的问题）。

**验证**: 精灵 147,390 → 56（三链 (13+5+11)×2 精确吻合、稳定不涨）；FPS
48 → 144；箭头恢复离散"三角+圆点"随带速连续流动（0.8s 帧对 ~0.4 格、无回跳）；
物品与箭头同格、堵塞红显 + 停走语义正常。tsc 干净 + test-output-polling /
t210 39 / t27 43 / diagnose-pointer-flicker S1~S10 全绿（89 次瞬移 = T2.27
笔记已知 v1 残留）。详见 `doc/实现笔记/T2.27-连续箭头流.md` 补记 T2.27-a。
