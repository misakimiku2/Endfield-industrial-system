# 集成工业系统 · Code Wiki

> 《明日方舟：终末地》"集成工业系统"玩法的复刻实现 —— 一款异星工场风格的 2D 工厂建造游戏（后续融合塔防元素）。
> 技术栈：**PixiJS v8 + 自研 ECS + TypeScript + Vite**，目标发布形态为 **Tauri 2.x 桌面应用**。

本 Wiki 由对仓库源码（约 1.35 万行 TypeScript）与既有设计文档的系统分析生成，面向需要理解、修改或扩展本项目的开发者。

---

## 快速开始

```bash
npm install              # 安装依赖
npm run pack-assets      # 【必须】生成 public/spritesheets/ 图集（不入库，克隆后首跑必做）
npm run dev              # 启动开发服务器 http://localhost:5173（端口固定，占用即报错）
```

详细运行/构建/调试说明见 **[10-运行与构建](10-运行与构建.md)**。

## 一图看懂（30 秒版）

```
index.html
  └─ src/main.ts ──────────── 唯一入口：初始化 PixiJS、接线输入、驱动主循环、暴露调试钩子
       └─ game/Game.ts ────── 组合根：创建 ECS World + 各子系统并确定执行顺序
            ├─ ECS.ts ─────────────── generation-based 实体管理 + 字符串 key 组件存取 + query
            ├─ GameLoop.ts ────────── 双时钟：20 TPS 固定步长仿真（BeltSystem → MachineSystem）
            ├─ world/ ─────────────── 地图尺寸（MapInstance）+ 占用判定（OccupancyMap）
            ├─ systems/ ───────────── 传送带 / 生产 / 放置 / 选中 / 删除
            ├─ render/ ────────────── 相机、场景分层、九宫格装配、传送带各渲染器
            ├─ data/ ──────────────── buildings / items / recipes（CSV 数据驱动）
            └─ ui/ perf/ ──────────── 工具栏、设备读数、性能监控
```

## 文档约定

- 代码位置以 `文件路径:行号` 形式引用（如 `src/game/ECS.ts:21`），行号基于撰写时的工作区状态，仅作定位参考。

- 本项目注释密度极高，代码文件头部普遍注明设计依据；Wiki 与注释冲突时，以代码实现为准。
