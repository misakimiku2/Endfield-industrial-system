## 遗留问题（会话记录 §四，T2.22b 语义的固有残差）

1. **箭头与物品不保证精确对齐**: 物品间距非整数格（轮询节奏不均）时，箭头网格与
   各物品错开最多 ±0.5 格；表现 = 箭头出现在物品紧邻位置（用户截图 log/crop1）。
2. **吸收瞬间的小幅网格移位**: 队首被吸收时锁定切换，回退量 = 间距 (mod 1)，
   非整数间距时全链箭头每次吸收跳 0~0.05 格（≈2.4px，约每 2 秒一次）。
3. 跨链衔接（A 链尾流入 B 链头）物品不对齐 B 链网格（瞬态）。
4. 调试钩子直接 push 的物品不在网格上（非玩家路径）。

## 修复一: 恢复 T2.22b 领头硬锁（`BeltPointerPhase.ts`）

- 有领头: `virt = 领头内插位置`（prevTick→lastSeen，停走零回跳）逐帧硬锁；
  删除漂移机制与 `prevLeader` 字段。
- 空链: `virt += 帧带速增量`（从最后领头位置无缝续流）；空链首件 = 一次干净
  再对齐（诊断分类"接受"——T2.21 设备级节拍下稳态链不全空，仅首件/清场后发生）。
- 语义与 v11 一致: 队列停→箭头停、队列进→箭头随行。

## 修复二: 槽位网格注入（`OutputOps.slotPlacement`，零节奏变更）

**根因分析**: 箭头网格 = 领头相位（硬锁），"物品替换箭头"天衣无缝要求**全链物品
与领头间距恒为整数格**。间距只在注入瞬间产生: T2.21 设备级 40-Tick 节拍与"带头
腾空"时序错开非整数 Tick（多带轮询被其他带抢占节拍窗口、门口排队恢复晚点）→
新物品与领头间距 = 1.0 + k×0.025（k≠0 mod 40）→ 离格。T2.23 用"出货门控等槽位
边界"对齐——改变了发货节奏手感，被撤销。

**新方案 = 注入时落到网格上**（节奏完全不变）: 注入进度 = `frac(链领头 total)`
（空链 = 段首 0）。注入物与领头的 mod 1 同余**精确成立**（对同一 float 取 frac），
间距 = floor(领头 total) 恒为整数格，且注入位置恰为当前箭头所在处——物品"变成"
箭头，视觉无缝。归纳可证全链物品恒在网格上（自由流动保距、钳制归 1.0、吸收更替
整数回退）→ 箭头与**每一件**物品精确对齐、吸收换位零跳变。

- `chainLeaderTotal(world, chainId)`: 链领头锚（total + 本 Tick delta，含 entering）。
- `chainDownstreamMin(world, beltAt, head, headPos)`: 下游最近非 entering 进度
  （与 BeltSystem 跨段钳制同口径）。
- `slotPlacement(leader, downMin)`: 纯函数放置决策；防御钳 `min(frac, downMin)`
  （链上有离格旧物品时防 <1 格重叠，离格物流出后网格自愈）。
- 注入 delta 跟随领头位移（流动 0.025 / 停走 0）→ 注入首帧与箭头位置**精确重合**
  （BeltItemRenderer/PointerPhaseClock 首帧均以 progress−delta 起步，同款约定）。
- **对在网链（frac=0）注入与旧版段首 0 逐字节一致**——正常观感零变化；只有离格
  链（跨链衔接/扰动后）介入，属网格自愈。出货节拍/轮询序/吞吐/首件时机全部不变
  （与 T2.23 的本质区别: 那次动了"何时出"，这次只动"落在哪"）。
- 调用点: `MachineSystem.emitBeltOutputs`（机器路径，离格主源）与 `updateDepot`
  unload（取货口路径，"段空即出"节奏下恒为段首 0，统一纪律）。

## 修复三: 门口边界浮点容差 ±1e-6（T2.23 遗产单独重做）

固定步长累加在边界下欺: 0.475+0.025 = 1.4999…（差 2e-16）→ entering 物品在
1.5 门口滞留 1 Tick（S9 实测 41 Tick）、后车多流 0.025。`IntakeOps
（releaseArrivedItems / doorHeadItem）` 与 `DepotOps.tryAbsorbHeadItemSink` 的
边界判定加 `- 1e-6`（≈0.05px，视觉不可辨）。

## 接受的例外（不修，记录口径）

- **跨链衔接**（A 尾→B 头）: 来件落在 B 的 progress 0，若 frac(B 领头) ≠ 0 则该件
  离格——瞬态（随流动被吸收），后续注入以 B 领头为锚自愈。
- **调试钩子**直接 push 的物品离格（非玩家路径）；由 `slotPlacement` 防御钳兜底
  不产生 <1 格重叠。
