# T2.22 — 指针相位连续性 · 实现笔记

> 任务卡: 用户 2026-09-05 实测报告（T2.21 输出轮询上线后"指针闪烁位移"）｜ 状态: 2026-09-05 完成 ✅
> 修订 BeltPointerRenderer 的相位计算（v11 领头跟随的 two 处不连续），不动物品/物流逻辑。

## 现象（用户报告）

炉子双输出带 A（正常传输）/B（物品到终点停止），**中途延长 B 后 A、B 指针都闪烁位移**；
A 每次闪烁时物品队列看似停顿或微后退一点。附带观察: 红堵时指针仍在走; 堵塞发生时
B 带物品间的指针立刻停、只有物品继续前进填空位。

## 诊断（scripts/diagnose-pointer-flicker.ts，驱动真实 BeltSystem+MachineSystem）

复现出两类真实跳变（按每帧相位增量偏离合法区间检测）:

1. **模式切换跳变（主因）**: v11 相位 = 领头物品跟随（有物品）↔ 自由时钟
   `globalPhase + chainId 哈希`（空带）。带清空瞬间相位从领头位置**跳到哈希时钟**、
   下一件注入**跳回 0**——每周期两次任意幅度跳变。T2.21 稀疏输出（多带各 1/N 频率）
   让短带（物品在带上寿命 < 到货间隔）**周期性清空** → 周期性闪烁（S2 场景: A=1 格
   接存货口，每 ~61 Tick 一对跳变，900 Tick 共 27 次）。旧密集输出下带不清空，
   此缺陷自 v11（2026-08-27）起潜伏、T2.21 后显形。
2. **领头插值回跳**: 领头位置公式 `progress + alpha·delta` 是**外推**——领头停走的
   Tick 边界（delta 0.025→0）相位回跳 ~0.025 格 = 用户"物品后退了一点点、不明显"
   的来源（箭头回跳被读作队列回退; 物品渲染自身 2026-09-02 已改 prev→cur 内插，
   无此问题——指针公式的孪生缺陷遗留）。

"红堵 + 指针在走"与"堵塞瞬间指针停/物品压缩"在四个场景**零复现为缺陷**:
- 堵塞瞬间指针停、物品继续填空位 = v11 既定语义（箭头跟随**队首**; 队首停→箭头停，
  后方物品压缩填位是停走逆流传播的物理过程，2026-08-27 用户拍板）。
- 红堵中指针走 = 链级红判定（任一物品停走）与领头恢复流动之间的瞬态/相邻链对比，
  加上堵塞渐变 tint（BLOCKED_BLEND_MS）滞后，非相位缺陷。

## 修复

新增纯逻辑模块 **`src/game/render/BeltPointerPhase.ts`（PointerPhaseClock）**，
BeltPointerRenderer 改为调用它取每段相位（渲染其余部分不动）:

- 每链维护**连续相位载体 virt**（未取模的领头等价位置）:
  - 有领头: `virt += 领头内插位置的帧增量`（≤0 钳 0——吸收/换领头的整数回退不打扰
    相位，mod 1 天然连续; **领头内插用 prevTick→lastSeen**（BeltItemRenderer 同款），
    停走 Tick 边界零回跳）; 领头移动时叠加 ≤10% 带速微漂移，把注入/非整格回退留下的
    常数相位偏移缓慢收敛回 v11 精确对齐（队列停走时不漂移）。
  - 无领头（空带）: `virt += 本帧带速增量`——**从领头离开的位置无缝续流**。
  - 领头刚出现: virt 不动——箭头保持流动原位、队列汇入，不再跳变对齐。
  - 链首次观测: 播种 `globalPhase + chainId 哈希`（同旧自由时钟，无连续性可破）。
- 语义与 v11 完全一致: 队列停→箭头停、队列进→箭头随行、空带继续流动、一格一物品
  （段上有物指针隐藏）不变; 唯一行为差异 = 注入瞬间箭头不跳变对齐，保持原位后随
  流动缓慢对齐（历轮被否决的都是"跳变/闪动"，缓变不在其列）。
- 链状态按帧回收（链消失即删，长会话不泄漏）; `reset()` 供场景重置/测试隔离。

## T2.22a 修订（同日用户复测反馈："空带越长箭头越快"+ 闪烁依旧）

**根因: 相位载体的推进被写进了按段循环**——`computePhases` 遍历全部段时，
每段的迭代都对**全链共享**的 `virt` 做一次 `+=`，N 段链每帧推进 N 次 = 箭头
N 倍速: 空带速度随链长线性加快（用户观察 ①），物品链上箭头比队列快 N 倍、
疯狂错位 = "闪烁没解决反而更糟"（用户观察 ②）。

修复: 推进与取相位拆开——先按出现序去重收集链、**每链推进恰好一次**，再按段
派生 `phase = (virt − segIdx) mod 1`。

**教训（诊断脚本漏检原因）**: 跳变容差 `sampleFlow + 0.03` 太松——每帧真实流动
≈0.008（60fps），N=2~3 的倍速增量（0.017~0.025）恰好落在容差内，S1–S4 全绿
给了虚假信心。已收紧为 `sampleFlow × 1.15 + 0.002`（合法上界 = 微漂移 10% + 浮点
余量），并新增 **S6 链长无关性**断言（1 格链与 5 格链空带速率均 = 0.025/Tick
且相等）。**帧增量类断言的容差必须贴着物理速度上界，宽松容差会把"速度错了 N 倍"
漏判成"无跳变"。**

## T2.22b 终稿（同日用户二次复测: 腾空格/队列前方箭头闪烁）

用户两现象: ① 单带物品填满时**队列前方的箭头**闪烁; ② 双带交替输出时，物品刚走出
设备**其所在格突然冒出指针又消失**。

**根因 = T2.22 初版的"保持原位 + ≤10% 微漂移收敛"设计错误**: 漂移速率收敛任意偏移
需数百帧（等效永不收敛），箭头相位与物品队列的**槽位周期永久错开**——物品跨入下一
格腾空的格子，箭头在格子中央凭空出现（v11 恰好出现在物品腾出的槽位边缘）、被下一个
物品替换时又消失 = 两个现象的统一解释。教训: **"不跳变"不能靠放弃对齐来买——两者
必须同时成立，而对齐是用户可感知的主性质。**

**终稿 = v11 精确锁定 + 内插领头 + 空链续流**（PointerPhaseClock 重写）:
- 链上有物品: `virt = 领头内插位置`（prevTick→lastSeen，保留 T2.22 的停走零回跳修复）
  逐帧**硬锁定**。队列流动时领头 total 连续: 跨段连续、吸收更替的后件恒落后整数格
  （流动锁步 1.0；entering 终点 1.5 与停走点 0.5 均 ≡0.5 mod 1）→ mod 1 无跳变。
  自动扶梯性质全部回归: 腾空格箭头出现在槽位边缘（S7-a）、前方箭头与队列同速滑动
  （S7-b: 箭头相位 = 队首 progress）。
- 空链: `virt += 帧带速增量`——从最后领头位置无缝续流（替代 v11 哈希时钟）。
- 空链首次注入: 一次干净再对齐（诊断分类为"接受"; T2.21 设备级节拍下 entering 行程
  与注入节奏重叠，稳态链不全空，仅首件/清场后发生）。
- 微漂移机制整个移除。

**诊断脚本方法论补充**: S7 初版误报——测量采样用恒定 alpha 导致 Tick 边界检测
（alpha 回卷）永不触发、内插状态冻结。**驱动内插时钟的测试装置必须模拟真实的
alpha 上升-回卷序列**（每 tick 多个上升采样）。

验证: S1–S4 非法跳变 0（仅存"空链注入再对齐"接受类）; S5 停走语义保持; S6 速度/
链长无关; S7-a/b 自动扶梯对齐 ✅; tsc 干净; t210/t27/t25/t212/输出模式回归全绿。
