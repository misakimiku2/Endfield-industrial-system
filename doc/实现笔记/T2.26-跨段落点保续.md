# T2.26 — 跨段落点保续（门口行走间距精确化）· 实现笔记

> 任务卡: T2.25 诊断日志的浏览器日志（log/localhost-1788638506029.log）分析结论——
> 用户残留闪烁定位到**跨段浮点阈值彩票**，一行落点修复 + 检测器校准 ｜ 状态: 完成 ✅

## 日志证据（T2.25 通道首战立功）

用户实测场景：3 条取货口→精炼炉的带（1 格链 ×1、2 格链 ×2）。65 次 ❗ 指针跳变、
56 次 ⚠ 物品离格、**0 次 ❗ 物品跳动**（物品渲染层无辜）。三类信号:

1. **⚠ 物品离格 −0.025（真缺陷，2 格链）**: `seg1@1.025E seg1@0.000`——entering
   领头行走在 seg1，后件跨段落点在 seg1@0，间距 1.025（离格 ≈1.6px）。
2. **❗ 指针跳变 前进0.979（=后退 ~0.022，真缺陷，2 格链）**: 领头移除 Tick，
   新领头（门口物品）的相位比旧领头落后 ~0.025 → 全链箭头回跳 ≈1px，
   **每条带每 2 秒一次 = 用户看到的残留闪烁**。
3. **❗ 指针跳变 0.474→0.000（误报，1 格链）**: 链在同一 Tick 内"领首移除+取货口
   再注入"，渲染层看不到空链帧，接受类判定漏判（箭头全程被物品遮住，不可见）。

## 根因: 跨段阈值浮点彩票

后件跨段条件 `headAdvanced >= 1.0`（headAdvanced = 累加浮点 + 0.025）。门口物品
被吸入（entering）后，后件与其**同一浮点序列**自由行进——理想情况下同 Tick 到达
"后件 1.0 / 领头 2.0"。但累加和落在 1.0 下欺（0.9999999999999999 < 1.0）时后件
**晚 1 Tick** 跨段:

- 落点 = 0（旧实现）→ 后件 total 1.0，领头已 2.025 → **间距 1.025 永久化**（离格）；
- 领头 1.5 移除时新领头 1.475 → **箭头网格回跳 0.025**（闪烁）。

残差交替出现（日志中 on-grid/off-grid 逐周期交替）= 门口 `Math.min` 钳制到常量
0.5 抹平残差、而自由行进段累加重新漂移的联合效应。与 T2.23 发现的门口下欺
（0.475+0.025 < 1.5）同根——**固定步长浮点累加的每个阈值都有这颗雷**。

## 修复

### ① 跨段落点保续（`BeltSystem.processSegment`，一行）

跨段落点从 `progress: 0` 改为 `progress: headAdvanced − 1.0`（越界余量，∈[0, 0.025)）:

- 逻辑 total 连续: `1 + 落点 == headAdvanced`——物品世界位置无跳变（旧落点 0 会
  吞掉本 Tick 已走过的 0.0249）;
- 与 entering 领头的间距**精确 1.0**: 后件与领头的行进是同一浮点序列，领头位置 ==
  后件 headAdvanced（同一 float）→ gap = (1+leader) − (1+leader−1) = 1.0 恒成立，
  **不再依赖阈值命中的运气**;
- 门口 `Math.min` 常量钳制（0.5/1.5）随后抹平残差——网格自愈、周期收敛。

### ② 检测器接受类校准（`BeltPointerRenderer`）

链状态从"有物品"改为二元组 `{any, active}`（active = 有非 entering 物品）。跳变
判定: 上一帧 `active === false`（链空或只剩 entering 行走物品）→ 再对齐归**接受类**。
覆盖同 Tick"移除+再注入"（渲染层看不到空链帧）的场景。
