## 2. 多端口 dev 服务器问题（用户困惑的根源）

- **现象**: `npm run dev` 显示 5173，但 5174/5175/5176/5177 也都能打开应用；不同端口
  可能跑着**不同版本的代码**（历次会话遗留的 vite 实例，测试完没关）。
- **本次已处理**: 已杀掉 5173(PID 38192)/5174(18772)/5175(38680)/5176(42412) 全部
  4 个实例，`netstat -ano | grep -E ":517[3-7]" | grep LISTENING` 确认清零。
  （含用户刚启动的 5173——已告知，新会话重新起即可。）
- **端口已固定（vite.config.ts `strictPort: true`，本轮已改并实测）**:
  dev 服务器**只会用 5173**；端口被占用时第二个实例直接报错
  `Error: Port 5173 is already in use` 退出，不再自动换端口。
  验收脚本默认 BASE_URL 已同步改为 `http://localhost:5173/`。
- **新会话标准流程**:
  1. `npm run dev` —— 显示 5173 即唯一实例；若报"Port 5173 is already in use"
     说明有残留实例: `netstat -ano | findstr ":5173"` 找 PID →
     `taskkill /PID <pid> /F` 杀掉后重跑；
  2. 浏览器打开 `http://localhost:5173/` 并 **Ctrl+Shift+R 硬刷新**（防模块缓存）；
  3. 验收脚本无需再带 BASE_URL 前缀（默认即 5173）。
- **历史教训**: 本会话曾发生"用户在 5173 测到旧现象、我修的代码在 5177 验证"的错位。

| v6 定稿 | 二值硬切: items 非空即隐藏，空段常显 | 队列前箭头提前消失/相邻贴边（后经 v11 定案：根源是物品与指针双时钟错位） |

| v8 | 全格蒙版裁剪 | 箭头过格被平切、截断 |
| v9 | 恒显 + 层级遮挡（物品盖箭头） | 转角/门口浮空箭头、物品速率与指针独立盖不住 |
