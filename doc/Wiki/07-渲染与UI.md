# 07 · 渲染与 UI

> 上一篇：[06-建造与交互系统](06-建造与交互系统.md) ｜ 下一篇：[08-数据与资产](08-数据与资产.md)

渲染模式：**自研 ECS query diff → PixiJS v8 场景图同步**。逻辑状态（组件）是唯一真相，渲染层每帧对齐，从不反向写入逻辑。

## 1. 场景分层 SceneRenderer.ts（83 行）

```
app.stage
├─ backgroundLayer  [屏幕空间] GridRenderer 的底色 + 网格线
├─ worldContainer   [世界空间] 相机变换写入此容器
│   ├─ layer0Terrain（空）      ├─ layer1Grid（空，网格在屏幕层画）
│   ├─ layer4Enemy（预留）      ├─ layer5Effect（预留）
│   ├─ layer2Building           带身 z0 ＜ 物品 belowItems z0.5 ＜ 设备 z1 ＜ 端口残段 z0(设备之下)
│   │                           悬停框 z15000
│   └─ layer3Item               端口高亮 z14000 ＜ 提示文字 z16000；传送带指针
└─ overlayLayer     [屏幕空间] 暗角 + InventoryUI 工具栏（不随视图旋转）
```

所有层 `sortableChildren: true`，层内用 zIndex 细排。

## 2. RenderSystem.ts（692 行）——每帧同步

`update(deltaMS, alpha)` 流程：

1. **diff 清理**：`world.query('Position','SpriteComp')` 与缓存 `entries: Map<handle, SpriteEntry>` 对比，消失的实体 `destroy({children:true})`；
2. **视口剔除**：屏幕四角逆变换 + `CULL_PADDING=128`，视口外 Sprite `visible=false`（不销毁）；
3. **实体循环**：
   - `BeltSegmentComp` 实体跳过 Sprite 创建（带身由 BeltVectorRenderer 接管）；
   - 纹理 diff 键 = `(group, textureKey, layer, nineslice)`，变更才重建；
   - 位置同步 = `pos + 有效占地/2`（`effectiveFootprint` 处理宽高互换）；建筑 `rotation = direction × π/180`；传送带用 `beltTextureRotation / beltCornerTransform`（CCW 转角 `scale.x` 取负镜像）；`roundPixels = true`（修非整数 zoom 亚像素灰缝）；
   - billboard 徽标 `rotation = camera.displayRotation − sprite.rotation`；
4. **专用渲染器依次刷新**：beltVector → pointer → beltItem → beltHover → portHighlight。

`spriteCount / visibleSpriteCount` 供 PerfMonitor 采样。

## 3. 相机 Camera.ts（484 行，纯逻辑类）+ CameraController.ts（268 行）

**Camera 状态**：中心 `(x,y)`、`zoom`、离散 `viewRotation ∈ {0,90,180,270}`、连续 `_displayRotation`（动画期弧度）、滚轮 target-lerp 模型。

| 能力 | 实现 |
|---|---|
| 坐标换算 | `worldToScreen / screenToWorld`（中心相对 → 旋转 → 缩放 → 平移，严格互逆）；`screenDirToWorld`（WASD/拖拽的屏幕相对平移） |
| 缩放 | `zoomByWheel`：target × (1 − deltaY/200)，`update()` 指数趋近（τ=0.08s 帧率无关）+ 容差吸附；范围 0.25~4.0（下限动态 = min(0.25, 视口/世界适配)） |
| 视图旋转 | Ctrl+R 循环 90°；`easeInOutCubic` 220ms 过渡；目标锁定精确弧度（修"连旋不回正"漂移） |
| 边界 | `clampPosition` 约束中心到世界内；世界小于视口时居中 |
| 输出 | `updateTransform()` 写 worldContainer：`scale=zoom, pivot=(x,y), position=视口中心, rotation=−displayRotation` |

**CameraController**（唯一直接监听 DOM 的相机层）：中键拖拽、滚轮缩放（preventDefault）、WASD/方向键 900px/s、边缘滚动（32px 触发带）、Ctrl+R、窗口失焦清键。

## 4. 网格 GridRenderer.ts（259 行）

屏幕空间方案（每帧重绘，密度恒定）：背景 #E6E4E4 + 1px 网格线 #D6D4D4（64px 世界间距）+ 暗角。

- **旋转感知**：每条世界网格线取两点 `worldToScreen` 得屏幕直线，参数化裁剪到视口再分 12 段着色；
- **边缘渐隐**：按视口对角线归一化，中心 55% 内 alpha=1，线性衰减到边缘 0.25；
- **暗角**：原生 Canvas 2D 径向渐变纹理，仅 resize 时重建。

## 5. 九宫格底座体系（设备视觉核心）

设备底座不再"整机一张图"，而是**切片拼装**，图集面积与设备尺寸彻底解耦（S2/S3 专题文档）：

- `baseStyle: 'nineslice'`（w,h ≥ 2）→ `NineSliceAssembler` 按 footprint 平铺 9 类底座切片（行0=tl/t…/行h−1=bl/b…，中间 m 系，72×72）；
- **端口变体切片**叠加：固体口 `port-*`（含黑色底板）→ 端口间分隔块 `emblazon-*`（相邻两格有固体口的边界，A/B 形交替）→ 液体口 `lport-*` → 侧边装饰条 `deco-l/r`；
- **单一真相源**：视觉端口 = `BuildingDefinition.ports` 的派生（`PortMask.portMaskFromDef`），不新增设备定义字段；方向约定：**顶=出口、底=入口、左=液体出、右=液体入**；
- `w=1 或 h=1`（如仓库口 3×1）走 `whole` 整图路径，永久兼容；
- **烘焙缓存**：已放置设备用 RenderTexture 按"尺寸+端口掩码"烘成单纹理（`getBakedNineSliceTexture`，resolution 4 + mipmap）——消除逐切片 mipmap 暗斑 + 把 100 台 6×6=3600 Sprite 降到每设备 1 个；无 renderer 时（单测）回退逐切片容器。

## 6. 传送带渲染器组

### BeltVectorRenderer.ts（338 行）+ BeltVectorGeometry.ts（263 行）

矢量 Graphics 带身（位图低 zoom 会把透明边距插值成灰缝）。每段一个 Graphics，`segShapeKey = isCorner|direction|entryDir|mirrorH` 变化才重绘。染色优先级：**选中（白/黄）＞ 堵塞（黄→红渐变 250ms）＞ 创建模式断头尾（→蓝 #80BEE9 渐变）**。几何纯函数提供直段/半格残段/转角圆环的绘制与精确尺寸常量（源自 SVG 素材测量）。端口半格残段恒挂 zIndex 0（设备之下，"钻入设备"观感）。

### BeltPointerRenderer.ts（514 行）——指针流动相位机制

黄色箭头指示带内流向。每段结构：位置容器 + StencilMask（端点裁剪）+ 指针 Sprite + 选中白 Sprite。

- **相位公式**：`本格相位 = ((leaderTotal − segmentIndex) mod 1 + 1) mod 1`，其中 `leaderTotal = max(segmentIndex + item.progress + alpha×delta)` 为链领头物品位置（v11 终稿：**箭头与队列锁步**——队列停箭头停；物品离开链后领头整格回退无跳变）；链上无物品回退 `全局相位 + chainHash 偏移`（空带继续流动，同链"自动扶梯"连贯）；
- **端点蒙版**：head/tail/single 用 StencilMask 裁剪（PixiJS v8 已知问题 workaround：Graphics mask 重画后必须 `mask=null` 再绑回）；
- **一格一物品**：段上有物品时指针 alpha 硬切为 0（无渐隐特效）；
- 直段沿流向滑入/滑出（端点外延半格由蒙版裁掉）；转角沿四分之一圆弧（pivot=进出边缘向量之和，朝向=切线+π/2）。

### BeltItemRenderer.ts（288 行）——物品渲染

- 物品 Sprite 统一挂 `belowItems` 容器（layer2Building 内 z0.5：带身之上、**设备之下**——"钻入设备"）；
- 纹理 = items 图集按 itemId；长边缩放到 32px（半格）；
- **帧间内插**：`renderProgress = prevTick + alpha × (lastSeen − prevTick)`——内插**永不超过逻辑位置**（零倒退零过冲）；Tick 边界无论 progress 是否变化都推进 prevTick，静止物品插值区间塌缩，消除 20Hz 微抖；
- 位置：直段线性；转角圆弧（与指针同源数学）；转角预约物品 progress>1 时沿出口方向直线延伸。

### BeltHoverRenderer.ts（150 行）

悬停带格 #FFCB00 四角 L 形 + 呼吸动画（周期 1.6s）。传送带创建模式下禁用。

### PortHighlightRenderer.ts（324 行）

每设备一个锚容器（位置=设备中心、rotation=direction），每端口 2~3 个 Sprite（面板/箭头/输出主体面板）。颜色：连接黄 `#FFEF00` ↔ 堵塞红 `#B10000` 渐变（250ms，数据源 PortStatusOps）；创建模式输出端口蓝 `#80BEE9`（悬停 `#A8D4F5`）；对接确认绿 `#37D067`；输入口起画红警示 `#E45050` + 文字"输入端口不能作为起点"。

## 7. 预览染色滤镜

| 文件 | 用途 |
|---|---|
| `PreviewTintFilter.ts`（205 行） | whole 设备预览：双纹理方案——主体染蓝/红 + 箭头 mask 精确变白；处理了图集 UV 与 render-target 坐标换算、mask 随旋转同步；fragment uniform 必须 `highp`（GLSL 精度一致性） |

## 8. 资产加载 AssetsLoader.ts（103 行）

- `AtlasGroup = 'devices' | 'items' | 'ui'`；`loadAllAssets()` 并行加载 `/spritesheets/{group}.json`；
- **纹理选项**（`ATLAS_TEXTURE_OPTIONS`）：`autoGenerateMipmaps + mipLevelCount 4 + linear + maxAnisotropy 4`（修 zoom<1 锯齿；首次上传前配置）；邻块渗色由打包期 `ATLAS_PADDING=8` 抑制；
- `getTexture(group, key)`：key 带 `.png` 后缀；命名约定 = 文件名去扩展 → 小写 → 非 `[a-z0-9]` 序列替换 `_`。
