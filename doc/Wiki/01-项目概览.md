# 01 · 项目概览

> 上一级：[README](README.md) ｜ 下一篇：[02-整体架构](02-整体架构.md)

## 1. 项目定位

本项目复刻《明日方舟：终末地》中的"集成工业系统"玩法：玩家作为"管理员"，以俯视网格视角远程规划**自动化产线**——铺设传送带、放置生产设备、连接配方链条，实现"原料进 → 产物出"的物流网络；后续版本将融合**塔防元素**（敌人入侵 + 自动炮台，Phase 3）。

世界观设定（见 `doc/architecture/economy-vision.md` EC-006）：玩家不亲临世界，操作的是名为"集成工业系统"的软件界面——网格俯视视角由此获得世界观合法性。

**当前状态**：Phase 1（引擎基座）全部完成；Phase 2（生产物流）主体完成、收尾中；Phase 3（无限世界/管道/电力/塔防）为规划内容，代码中已预留接口。

## 2. 核心玩法特性（已实现）

| 特性 | 说明 | 主要代码 |
|---|---|---|
| 设备放置 | 工具栏选设备 → 鼠标预览（蓝/红染色）→ R 四向旋转 → 左键落盘，支持连放 | `systems/PlacementSystem.ts` |
| 四向旋转 + 占地互换 | 非正方形设备（如 3×1 仓库口）90°/270° 旋转时占地宽高互换（3×1↔1×3） | `data/buildings.ts effectiveFootprint` |
| 传送带创建 | E 键进入创建模式，从设备输出端口或断头带尾起画，实时寻路预览、终点吸附输入端口 | `systems/BeltCreationSystem.ts` |
| 物品运输 | 0.5 格/秒、一格一物品，跨段传输、间距保持、堵塞整链变红 | `systems/BeltSystem.ts` |
| 生产系统 | CSV 配方驱动，idle/working/blocked 状态机，原子结算（计时完成才扣原料+落产物） | `systems/MachineSystem.ts` |
| 端口对接 | 端口几何由 `BuildingDefinition.ports` 派生；带→口预约制吸入、口→带空段注入 | `systems/machine/*Ops.ts` |
| 端口轮询 | 输入口"先到先得"排名走访；输出口活跃队列轮转 + 堵塞恢复探测 | `components/BuildingComp.ts` |
| 仓库口 | 取货口（无限源，凭空放出源矿）/ 存货口（无限汇，无条件吸入） | `systems/machine/DepotOps.ts` |
| 相机 | 平移（中键/WASD/边缘滚动）、滚轮缩放（0.25~4.0）、Ctrl+R 视图四向旋转 | `render/Camera.ts` |
| 设备视觉 | 九宫格底座 + 端口变体切片自动拼装，图集面积与设备尺寸解耦 | `render/NineSliceAssembler.ts` |
| 状态视觉 | 设备 logo 三态（normal/paused/blocked）、传送带堵塞红、端口连接黄/堵塞红 | `systems/RenderSystem.ts` 等 |

## 3. 技术栈

| 层面 | 选型 | 说明 |
|---|---|---|
| 渲染 | **pixi.js ^8.19.0**（唯一运行时依赖） | WebGL/WebGPU 2D 渲染，图集 + Sprite + Graphics + Filter |
| 语言 | TypeScript ~5.7.2（strict 全开） | `noUnusedLocals/noUnusedParameters` 等 |
| 构建 | Vite ^6.0.0 | dev 端口固定 5173（strictPort）；生产 target es2020；pixi 单独拆 chunk |
| 桌面壳 | Tauri 2.x（@tauri-apps/cli ^2.11.4） | WebView 装载 `dist/`，无自定义 IPC，前端代码与 Web 版完全一致 |
| 资产工具 | sharp ^0.35.3 | SVG 光栅化（4× 超采样）+ 图集打包（仅构建期使用） |
| 数据源 | CSV（`doc/csv/recipe.csv`、`doc/csv/终末地资源列表 - 自然资源.csv`） | 经 Vite `?raw` 导入，运行时解析为物品/配方注册表 |

**架构风格**：自研轻量 ECS（无第三方 ECS 库）+ 数据驱动（建筑/物品/配方全部声明式定义）+ 双时钟仿真（20 TPS 逻辑 / 60 FPS 渲染）。

```
│  ├─ csv/                     # ★ 配方/物品数据源（运行时经 ?raw 导入）

│  ├─ pack-assets.ts           # ★ 资产打包：SVG/PNG → public/spritesheets/{devices,items,ui}.{png,json}
│  ├─ assets/                  # 打包清单（asset-manifest.ts 单一真相源）与 shelfPack 算法
│  └─ verify-*.ts              # 28 个里程碑验证脚本（node --experimental-strip-types 直跑）
├─ public/
│  └─ spritesheets/            # 打包产物（.gitignore 不入库，克隆后须先跑 pack-assets）
├─ src/
│  ├─ main.ts                  # ★ 唯一入口（~1800 行）：初始化/输入接线/主循环/调试钩子
│  ├─ vite-env.d.ts
│  ├─ types/tauri.d.ts         # 占位（桌面壳类型，暂无实际 API）
│  ├─ assets/                  # 源资产：svg/（设备、UI）、png/（物品图标）
│  └─ game/
│     ├─ ECS.ts                # ECS 核心：World 类（实体/组件/query）
│     ├─ Game.ts               # 组合根：创建并接线所有子系统
│     ├─ GameLoop.ts           # 双时钟固定步长仿真循环
│     ├─ ObjectPool.ts         # 对象池（Phase 3 预留，未被引用）
│     ├─ components/           # 纯数据组件（BuildingComp、BeltSegmentComp、SpriteComp…）
│     ├─ world/                # MapInstance（地图尺寸）、WorldData、OccupancyMap（占用表）、Chunk（占位）
│     ├─ systems/              # 游戏系统（详见各专题文档）
│     │  ├─ BeltCreationSystem.ts / BeltSystem.ts / MachineSystem.ts
│     │  ├─ PlacementSystem.ts / SelectionSystem.ts / DeleteSystem.ts / RenderSystem.ts
│     │  ├─ PortGeometry.ts / RotationPolicy.ts
│     │  ├─ belt/              # 传送带子模块：寻路/几何/链操作/对接/选中
│     │  └─ machine/           # 生产子模块：ProductionOps/IntakeOps/OutputOps/BufferOps/DepotOps/PortStatusOps
│     ├─ render/               # 渲染层（详见 07-渲染与UI）
│     ├─ data/                 # buildings.ts / items.ts / recipes.ts（声明式数据 + CSV 解析）
│     ├─ ui/                   # InventoryUI（工具栏）、DeviceReadout、HUD（占位）
│     └─ perf/                 # PerfMonitor（FPS/内存基准）
└─ src-tauri/                  # Tauri 桌面壳（Rust）：窗口 1280×720，无自定义命令
```
