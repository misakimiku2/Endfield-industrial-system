## 概览

zoom=4 时设备图标锯齿的根因是 **T1.3 资源管线**：`pack-assets.ts` 的 `rasterizeSvg` 把 SVG 按 **1:1 原始像素尺寸**栅格化（1×1 设备纹理只有 64×64 像素），zoom=4 时被放大 4 倍导致模糊锯齿。T1.6 渲染系统逻辑正确（位置/视口剔除/旋转都对），它无法凭空制造纹理里不存在的细节。

**修复方案：SVG 高倍率光栅化（4×）**，匹配 `CAMERA_ZOOM_MAX=4.0`，保证最大缩放下纹素:屏幕像素 = 1:1。同时不破坏你想要的"端口变色"动态效果——位图多帧切换是最成熟的实现方式，SVG 源不会让变色更简单。

## 影响范围（仅 devices 图集）

| 图集 | 源 | 是否提倍 | 原因 |
|------|-----|---------|------|
| **devices** | SVG 矢量 | ✅ **4×** | 地图建筑，会随 zoom 放大；矢量可无损提倍 |
| items | PNG 位图 | ❌ 1× | 物品图标用在 UI 固定尺寸，无矢量源无法超采样 |
| ui | SVG 矢量 | ❌ 1× | 界面部件屏幕空间固定尺寸渲染，提倍无意义 |

devices 图集变化：1024×256 → 4096×1024（面积 ×16）。但 devices 源是矢量 SVG，PNG 压缩后体积远小于 items.png(5.4MB)，预估几十 KB 级。

## 改动清单

### 1. `scripts/assets/asset-manifest.ts` — 新增图集缩放配置

给 `AtlasGroup` 接口加一个可选字段 `rasterScale?: number`：
```ts
export interface AtlasGroup {
  // ...现有字段
  /** SVG 光栅化倍率（仅对 SVG 源生效）。devices=4 匹配 CAMERA_ZOOM_MAX，items/ui 不填=1。 */
  rasterScale?: number;
}
```
devices 分组加 `rasterScale: 4`。同时新增导出常量 `DEVICE_RASTER_SCALE = 4`（单一真相源，便于别处引用/校验）。

### 2. `scripts/pack-assets.ts` — `rasterizeSvg` 接收倍率

核心改动：`rasterizeSvg(svgPath, scale)`。
- **逻辑**：先解析 SVG 原始 width/height（现有逻辑保留），光栅化时 `resize(width*scale, height*scale, {fit:'fill'})`。SVG 是矢量，sharp 在更大目标尺寸下重新栅格化 → 真实高分辨率像素。
- **传递**：`collectGroup` 把 `group.rasterScale ?? 1` 透传给 `rasterizeSvg`。PNG 路径（`readPng`）不提倍（PNG 无矢量源，放大只是插值，无意义）。
- 打包/JSON：光栅化后的 `raster.width/height` 已是放大尺寸（如 1×1 设备 → 256×256），后续 `shelfPack` 和 JSON frame 自动用这个尺寸——无需改 packer。`sourceSize` 也自动是放大值。

### 3. 重新生成图集

`npm run pack-assets` 重新打包。验证 devices.json 的 frame 尺寸变成 4×（transport_belt 256×256、refining_unit 768×768）。

### 4. T1.6 RenderSystem 无需改动

`createEntry` 已用 `sprite.width/height = spr.width`（世界像素 64×64）覆盖纹理尺寸——PixiJS 自动把 256×256 高分辨率纹理缩放到 64×64 世界空间，zoom=4 时正好 1:1。已验证（`RenderSystem.ts:137-138`）。

### 5. 新增验证：`scripts/verify-assets.ts`（可选但推荐）

校验打包产物尺寸符合预期：
- devices 各纹理 frame 边长 = SVG 原始边长 × 4（容差 1px，因 sharp 浮点）
- items/ui 纹理 frame 边长 = 源尺寸 × 1
- 图集边长 ≤ MAX_ATLAS_SIZE(4096)，且为 POT

（沿用现有 verify 脚本风格，`node --experimental-strip-types` 直接跑，不依赖运行时。）

## 风险与回归

- **图集体积**：devices 预估仍 < 1MB（矢量源 PNG 压缩好），不影响加载。
- **打包时间**：9 个 SVG × 4× 光栅化，sharp 处理矢量很快（<1s）。
- **RenderSystem/相机不受影响**：纹理分辨率变化对它们透明（都用世界坐标 + sprite.width 覆盖）。
- **端口变色效果不受影响**：多帧切换/滤镜着色在位图层操作，与源格式无关。
