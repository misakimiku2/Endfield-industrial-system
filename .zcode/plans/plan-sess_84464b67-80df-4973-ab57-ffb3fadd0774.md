## 问题
预览染色颜色完全错乱。

## 根因（已读 PixiJS v8 源码确认）
filter 里 `uTexture`（设备原图）**不是 spritesheet 图集纹理**，而是 PixiJS filter 系统从 `TexturePool` 借出的**独立 render-target**——sprite 先画进 render-target，filter 再采样它。所以：
- `vTextureCoord` 是 render-target 内坐标（范围 `[0, bounds/po2]`，非图集 UV）
- `uMaskTexture` 我绑定的是**整个图集 source**（4096×1024），`texture(uMaskTexture, vTextureCoord)` 用 render-target 坐标去采整个图集 → 采样错位 → 颜色错乱

我之前 filter 注释写的"mask 帧与设备帧 UV 一致...共用 vTextureCoord"是错误假设。设备帧经 render-target 中转已"去图集化"，mask 帧没有。

另一个诊断误导：之前 `maskTexture.uvs` 返回 `[]` 误判为空。实际 PixiJS v8 的 `.uvs` 是**对象**（`{x0,y0,x1,y1,x2,y2,x3,y3}`），不是数组，被当数组读才显示空。

## 方案：方案 A（mask 留图集 + UV rect uniform 坐标变换）
bug 本质是"坐标变换缺失"，不是"打包架构错误"。图集同时输出设备帧+mask 帧共享 sourceSize 的设计是正确且优雅的（保证像素 1:1 对齐、共享抗锯齿边缘）。只需在 shader 里补上被遗漏的坐标变换。

### 改动（仅 1 个文件：`src/game/render/PreviewTintFilter.ts`）

**1. shader 增加坐标变换**：声明 filter 内置 uniform `uInputSize`、`uOutputFrame`（系统自动注入，无需 resources），外加 `uMaskUvRect`（mask 帧在图集的 UV rect）。采样 mask 时：
```glsl
vec2 local01 = vTextureCoord / (uOutputFrame.zw * uInputSize.zw);  // 还原设备局部[0,1]
vec2 maskUv = mix(uMaskUvRect.xy, uMaskUvRect.zw, local01);        // 映射到 mask 帧图集 UV
float arrowWeight = texture(uMaskTexture, maskUv).r;
```

**2. resources 增加 maskUniforms**（UniformGroup，含 `uMaskUvRect`）：
```ts
resources: {
  uMaskTexture: Texture.EMPTY.source,
  maskUniforms: new UniformGroup({
    uMaskUvRect: { value: new Float32Array([0,0,1,1]), type: 'vec4<f32>' },
  }),
}
```

**3. setMask 读 Texture.uvs 对象算 UV rect**（自动适配图集重排/rotate/trim，不手算）：
```ts
setMask(maskTexture) {
  const tex = maskTexture ?? Texture.EMPTY;
  this.resources.uMaskTexture = tex.source;
  const u = tex.uvs;  // 对象，非数组
  this.resources.maskUniforms.uniforms.uMaskUvRect = new Float32Array([u.x0, u.y0, u.x2, u.y2]);
}
```

**4. 更新 filter 注释**：修正错误的"UV 一致"假设，说明 render-target 中转 + UV rect 变换机制。

### 不改动
- `pack-assets.ts`、`AssetsLoader.ts`、`PlacementSystem.ts`（setMask 调用点签名不变）

### 验证
- TypeScript 编译（`npx tsc --noEmit`）
- 浏览器实测（Vite + agent-browser）：
  - 预览态（蓝）：设备主体纯蓝、箭头白、端口无缝隙、**颜色不再错乱**
  - 预览态（橙红）：同上，主体橙红
  - 放置后：设备保持原始外观
  - 关键校验：读 `setMask` 注入的 uMaskUvRect 值，确认约 `[0.188, 0.002, 0.377, 0.752]`（mask 帧 772,2,768,768 在 4096×1024 图集中的 UV）
