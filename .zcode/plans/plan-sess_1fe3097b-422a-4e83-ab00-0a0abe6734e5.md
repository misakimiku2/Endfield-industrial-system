# 传送带选择/悬停视觉重构

## 目标
移除现有选择样式（白边 + 45°斜杠 + 选中隐藏 pointer），改为：
- **悬停(hover)**：橙色四角 L 形边框（`#ffcb00`，取自 Transport_1.svg）+ 平稳呼吸（四角向内收拢）。
- **选中**（单击单格 / 双击整链 → **整链全变色**）：带身变色（灰壳`#B1B1B1`、黄带`#FFF56A`）+ pointer 变白（`#FFFFFF`）。

## 素材（pointer 变白用「白色 base + tint」方案）
1. `src/assets/svg/pointer.svg`：`fill:#dfb615` → `fill:#ffffff`（白色 base，tint 才能乘到任意亮色）。
2. `npm run pack-assets` 重新打包 spritesheet。

## 文件改动（8 处）

### 1. `src/game/render/BeltVectorGeometry.ts`
- `drawStraightBelt/drawCornerBelt` 签名：`(g, cellSize, overrideColor?)` → `(g, cellSize, colors?: { shellColor?: number; beltColor?: number })`；resolveShellColor/resolveBeltColor 改读 colors（缺省=原色）。
- 新增常量：`BELT_COLOR_SHELL_SELECTED = 0xb1b1b1`、`BELT_COLOR_BELT_SELECTED = 0xfff56a`。
- 删除（移除旧样式后无人引用）：`drawStraightBeltSelectionUnderlay`、`drawCornerBeltSelectionBorder`、`drawBeltYellowShape`、`SELECTION_RIM`、`BELT_COLOR_STRIPE`。

### 2. `src/game/render/BeltVectorRenderer.ts`
- 删白边 import + 调用（L26/27/116/118）。
- 选中变色：`selected ? drawStraightBelt(g,CS,{shellColor:SHELL_SEL,beltColor:BELT_SEL}) : drawStraightBelt(g,CS)`，转角同理。
- `segShapeKey` 追加 `|${selected?'sel':'ns'}`，选中态切换时重画。

### 3. `src/game/render/BeltPointerRenderer.ts`
- 删 `sprite.visible = !selected`（pointer 始终可见）。
- 每帧 `sprite.tint = selected ? 0xFFFFFF : 0xDFB615`。

### 4. `src/game/render/BeltSelectionRenderer.ts` — **删除整个文件**

### 5. `src/game/render/BeltHoverRenderer.ts`（**新建**）
- 挂 `layer2Building`，`zIndex=15000`；单个 Graphics 画 4 个 L 形角。
- API：`setMouse(sx,sy,inside)` / `setEnabled(bool)` / `update(elapsedMS)` / `destroy()`。
- update：`!enabled||!inside` → 隐藏；否则 `pickBeltSegmentAt(world,wx,wy)`（已 export，SelectionSystem L99）找 hover 段 → 有则画 4 角，无则隐藏。
- L 形角（CELL_SIZE=64，世界像素）：线宽 W=5、臂长 L=15；左上角 path（m=margin）：`(m,m)→(m+L,m)→(m+L,m+W)→(m+W,m+W)→(m+W,m+L)→(m,m+L)→close`，fill `0xffcb00`；其余三角镜像。**不旋转**（四角永远朝四方）。
- 呼吸：`margin = 2 + 3*(0.5+0.5*sin(2π*elapsedMS/1600))`，∈[2,5]px，周期 1.6s（向内收拢）。

### 6. `src/game/systems/RenderSystem.ts`
- 删 `BeltSelectionRenderer`（import/字段/构造/update L213/setBeltSelection 转发）。
- 加 `BeltHoverRenderer`（字段/构造/update 传 elapsedMS）。
- 新增 `setBeltHoverMouse(sx,sy,inside)`、`setBeltHoverEnabled(bool)` 转发。

### 7. `src/main.ts`
- `onPointerMoveMain` 加 `renderSystem.setBeltHoverMouse(p.x,p.y,inside)`。
- 进/出传送带创建模式（E）时 `setBeltHoverEnabled(!belt.isActive())`。

### 8. `src/game/systems/BeltCreationSystem.ts`
- `drawPreview` 4 处：`draw...(g,CS,previewColor)` → `draw...(g,CS,{shellColor:previewColor,beltColor:previewColor})`。

> `BeltSelection`（选中态数据）保留 —— BeltVectorRenderer / BeltPointerRenderer 仍读它做变色；只是不再驱动斜杠/白边/隐藏。`pickBeltSegmentAt` 已 export，无需改。

## 验证
1. hover：悬停传送带 → 橙色四角边框 + 呼吸；离开或进入创建模式(E) → 消失。
2. 单击单格：灰→#B1B1B1、黄→#FFF56A、pointer→白。
3. 双击整链：整链全变色 + pointer 全白。
4. 旧样式全消失：无白边、无斜杠、选中不再隐藏 pointer。
5. `tsc --noEmit` 通过 + 浏览器像素级抽查。
