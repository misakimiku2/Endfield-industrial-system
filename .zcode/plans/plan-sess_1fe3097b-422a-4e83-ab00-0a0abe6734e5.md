# 传送带多选：Shift 范围连选 + Ctrl 点选切换

## 需求（已澄清）
- **Shift + 左键单击**：范围连选（像选文件）。点 A → Shift 点 E → 选中 A 到 E 之间（同链）所有段。
- **Ctrl + 左键单击**：点选切换（toggle，加入/移除单格）。
- **普通左键单击**：替换（当前行为，单格/双击整链）。
- **左键单击空白**：清空（无修饰键时）。
- **不做框选**（那是未来设备多选，本次只做传送带点击式多选）。

## 文件改动（3 处）

### 1. `src/game/systems/belt/BeltSelection.ts`
新增两个 API（Set 已有，只是暴露）：
- `toggle(handle)`：集合中切换（有则删、无则加）。
- `getHandles(): EntityHandle[]`：返回当前选中段数组（Delete 批量删用）。

### 2. `src/game/systems/SelectionSystem.ts`
- 新增字段 `anchorBelt: EntityHandle | null` —— Shift 范围连选的起点（= 上次**普通单击**的段；Ctrl/Shift 操作不更新它，与文件选择语义一致）。
- `onPointerDown/Up` 增加 `mods: {shift, ctrl}` 参数（main.ts 透传 `e.shiftKey/e.ctrlKey`），`pendingPress` 记录 mods。
- `onPointerUp` 分支（短按前提下）：
  - **普通** belt：`beltSelection.set([handle])`（双击则 `set(queryChain)`），`anchorBelt = handle`。
  - **Ctrl** belt：`beltSelection.toggle(handle)`，anchorBelt 不变。
  - **Shift** belt：调 `selectRange(target)`，anchorBelt 不变。
  - 设备：`beltSelection.clear()`，anchorBelt=null。
  - 空白（无 Ctrl/Shift）：`beltSelection.clear()`，anchorBelt=null。
- 新增 `selectRange(target)`：
  - anchorBelt 与 target **同链** → `queryChain` 取链段 → 按 `segmentIndex` 升序排 → 选中 `anchorPos` 到 `targetPos` 之间（含两端）的段 `beltSelection.set(slice)`。
  - 不同链 / 无 anchor → 退化为 `beltSelection.set([target])` 并把 anchorBelt=target。
- **`update()` 改造**：不再每帧 `beltSelection.clear()`（改为持久，由交互维护）；只保留设备选中框（`drawDeviceBox`）+ selected 销毁检查。渲染端（BeltVectorRenderer/BeltPointerRenderer 读 `beltSelection.has`）天然支持多选变色，无需改。
- `clearSelection()`：额外清 `anchorBelt`。

### 3. `src/main.ts`
- `onPointerDownMain`：左键转发时带 `{ shift: e.shiftKey, ctrl: e.ctrlKey }`。
- `onPointerUpMain`：同样透传 shift/ctrl。
- `onKeyDelete`：改为按 `beltSelection.getHandles()` 批量删除（逐个 `deleteSegment`），而非单选 `getSelectedChain`；无 belt 选中时仍走设备删除。

## 验证
1. `spawnBelt` 一条 6 格链 → 单击 A（选 A，anchor=A）→ Shift 单击 E（选中 A-B-C-D-E）→ Ctrl 单击 C（C 从选中移除）→ 再 Ctrl 单击 C（C 加回）。
2. Shift 跨链点（不同链的段）：退化为只选目标段。
3. Delete 多选：一次删掉所有选中段。
4. 普通单击替换：有多选时，普通单击清空多选只选单格。
5. `tsc` 通过 + 浏览器抽查。

## 不改动
- 渲染（BeltVectorRenderer/BeltPointerRenderer/BeltHoverRenderer）—— 已通过 `beltSelection.has` 支持多格。
- 框选 / 设备多选 —— 未来再做。
