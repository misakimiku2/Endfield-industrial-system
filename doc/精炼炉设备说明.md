# 精炼炉（Refining Unit）

# 精炼炉的占地面积网格示意
| 0,0 | 1,0 | 2，0 |  
|-----|-----|------|
| 0,1 | 1,1 | 2,1  |
| 0,2 | 1,2 | 2,2  |

- 0,0、1,0、2,0为输出端口网格
- 0,1、为液体输出口、2,1为液体输入口（液体功能暂未实现）
- 0,2、1,2、2,2为输入端网格
> 精炼炉为基础生产设备模板，后续所有生产设备默认继承本说明中的输入、输出、生产计时、缓冲区锁定及轮询规则，如无特殊说明，仅修改设备尺寸、配方、生产时间及槽位数量。
## 描述
- 精炼炉属于基础生产设备。有 **1 个固体输入槽 + 1 个固体输出槽**，每个槽的物品上限为 50 个。
- 精炼炉**没有"加工位"这一设定**。生产过程只是一个**生产计时器**（参照《明日方舟：终末地》游戏原版）：当输入槽的原料满足某配方时，设备启动计时（**此时不扣除原料**）；计时走完后，才发生一次原子结算——同时扣除输入槽的原料、向输出槽加入产物。
- 精炼炉同一时间只有一个生产计时（单设备单计时器）。
> **吸入点确认（2026-08-17 用户拍板，已实现 ✅）**: 本节"物品走到 0,2（输入端口格）中心停止后才算进入设备"为目标行为，
> 已于同日以**预约制两阶段**实现闭环：物品在 0,3 供给格中心预约（输入槽 count+1）并继续前进（视觉走进设备半格深处），
> 到达 0,2 端口格中心后消失。堵塞时物品停在 0,3 供给格中心，与下文描述一致。
> 实现细节见 implementation-phase-2.md T2.6「吸入点=端口格中心」与 A9 logistics-spec.md §3.3 修订注。
- 精炼炉有三个输入端口、三个输出端口。
    - 当物品通过传送带传入精炼炉的输入端口时，精炼炉的输入槽 count +1，传送带传入物品时需要根据传送带物品停止的位置来进行判断，当前传送带的物品会停在传送带的中心位置。示例：
       - 物品从0,3的网格往0,2的输入网格传输物品，物品需要走到0,2网格的中心停止后，才算是进入到设备中。当输入槽满50个时，传送带的物品将会堵塞，物品无法进入到生产设备中，传送带的物品在走到0,3之后停留在0,3这一格。
       - 当物品走到0,2网格的中心后会消失，后面的物品会持续往输入端口传输物品。
       - 当输入槽数量不足50个时，三条传送带上的物品可同时传入生产设备，当输入槽数量到达50个时，此时所有传送带会停止传输，呈现堵塞现象，传送带上的物品会自然的停止在0,3的位置。
       - 如果生产设备结算扣除了一个物品导致数量下降到49，那么传送带会按照连接输入端的顺序进行依次传输，假如连接0,2、1,2、2,2输入端口的顺序是从左往右连接的A(0,2)、B(1,2)、C(2,2)传送带，那么会会先从A传送带进行1个补货，B、C传送带停止，A传送带补完1个物品之后，A便停止传输，此时生产设备内的物品又回到了50个的数量，当这50个物品又因为结算下降到49个物品时，B传送带开始1个补货...依此类推。
       - 输入轮询指针不会因为设备满载而重置，而是保持当前位置继续轮询。例如：A成功那么下一次应该直接轮到B而不是重新A。
    - 当从生产设备的输出端口创建传送带时，物品会从该传送带传输出去，当输出槽的物品数量为0时，
    - 当创建了多个输出传送带时，会根据创建传送带的顺序依次把物品传输出去，示例
        - 假如连接0,0、1,0、2,0输出端口的顺序是从左往右连接的1(0,0)、2(1,0)、3(2,0)传送带，那么物品会先从1传送带传输出去，然后就是2、3传送带。顺序为1-2-3-1-2-3...确保每条传送带都能有物品传输。
        - 假如1传送带发送了堵塞，那么顺序就会变成2-3-2。堵塞端口不会参与当前轮询，但不会被永久移除。当其恢复可输出时，将重新加入轮询。
        - 当堵塞端口恢复可写时，将其追加到当前轮询顺序的末尾。例如当前顺序为2→3→2，端口1恢复后，顺序变为2→3→2→1
- 精炼炉可生产的物品可在 recipe.csv 中查询到。
> recipe.csv 中原料需求字段使用 "/" 分隔多个原料，例如："源矿1/晶体外壳粉末1" 表示该配方需要消耗1个源矿或1个晶体外壳粉末（多选一）。
- 精炼炉同一时间只能处理一次生产任务。当物品进入到精炼炉时，会根据配方自动进行匹配，如果输入的物品在设备的配方中不存在，那么将不会进行生产，但是可以持续输入直到达到上限。**匹配成功后只启动计时，并不扣除原料**；生产时间与配方绑定。示例：
    - 当一个源矿进入到精炼炉后，精炼炉会立刻匹配到晶体外壳配方。若当前无生产计时（设备空闲），则启动计时（**不扣源矿**），生产时间为2秒。生产期间源矿始终停留在输入槽中。2秒计时完成后，**原子结算**：输入槽扣除1个源矿、输出槽加入1个晶体外壳。若输入槽仍满足配方条件，则立即启动下一次计时。
    - 当输出槽的固体产物数量达到上限50个时，此时即使计时已完成也无法结算（原料不会被扣，继续停留在输入槽），设备弹窗显示"阻塞"现象。输入物品依旧可以持续输入，直到达到输入槽的50个物品上限。
    - 当输出槽腾出空间后，结算立即执行（扣输入 + 加输出），设备恢复正常。

### 关于液体端口（Phase 2+）

精炼炉的网格 0,1 为液体输出口、2,1 为液体输入口（液体功能 Phase 1 不实现）。部分配方涉及液体原料或液体产物：

- **赤铜块配方**：`赤铜矿*1 + 清水*1 → 赤铜块*1 + 污水*1`，其中**清水**（原料）走液体输入口，**污水**（副产物）走液体输出口，二者**不占固体输入/输出槽**。
- **Phase 1-2 不实现液体系统**，因此 Phase 1-2 的精炼炉只能生产纯固体配方（晶体外壳、蓝铁块、紫晶纤维、碳块、密制晶体、钢块、高晶纤维、稳定碳块、致密晶体粉末共 9 个），**赤铜块配方在 Phase 3b 液体/管道系统完成后才启用**。
- 固体输入槽（赤铜矿）和固体输出槽（赤铜块）的槽位结构在 Phase 1/2 保持一致，Phase 2 只是解锁液体配方。

### 输入槽规则

- 输入槽用于存放等待生产的原料。
- 精炼炉只有一个固体输入槽，因此该槽一次只能锁定一种物品类型。
- 当第一件物品进入输入槽后，输入槽立即锁定该物品类型。
- 输入槽锁定期间，只允许相同类型的物品继续进入，不同类型的物品无法进入设备，并停留在传送带上等待。
- 当输入槽数量降为0时，立即解除锁定，下一件进入设备的物品将重新决定输入槽的物品类型。
- 输入补货时，轮询到的端口必须同时满足以下两个条件，补货才算成功：
    - 该端口有物品等待传入。
    - 该物品类型与当前输入槽锁定的类型一致（或槽为空时，该物品可成为新的锁定类型）。若端口物品类型不匹配，则该物品停留在传送带上，轮询指针立即移动到下一个端口，继续尝试补货。

### 生产计时规则

- 精炼炉拥有一个生产计时器（无独立"加工位"概念）。
- 计时器一次只能记录一个生产任务。
- **启动生产时不扣原料**：当输入槽满足某配方且设备空闲时，启动计时（记录配方、progress=0），原料继续停留在输入槽中。
- **计时完成时才扣原料（原子结算）**：计时走完后，同时扣除输入槽的原料、向输出槽加入产物，然后清空计时。若输入槽仍满足配方，则立即启动下一次计时。
- **结算失败（输出满）**：若输出槽已满，结算不执行，原料继续停留在输入槽（未被扣除），设备进入阻塞状态，等待输出槽腾出空间。

### 高级设备（未来支持）

- 高级生产设备拥有多个固体输入槽（如反应池、研磨机需要两种固体原料，故有 2 个输入槽）。
- 每个输入槽分别锁定一种物品类型，槽位数量根据该设备配方所需的最大固体原料种类数决定。
- 每个输入槽都遵循与精炼炉相同的锁定规则。
- 输入槽在数量大于 0 时锁定当前物品类型，只允许相同类型的物品继续进入。当输入槽数量降为 0 时，立即解除锁定，下一件进入该槽的物品将重新确定该槽的物品类型。
- 液体（清水、污水等）走专用液体端口，不占固体输入/输出槽。

## 设备事件执行顺序

精炼炉采用事件驱动方式运行，不存在固定的检测周期。当设备发生以下事件时，会立即执行对应逻辑：

- 输入物品进入输入槽。
- 当前生产计时完成。
- 输出槽恢复可写（解除阻塞）。
- 设备创建或加载完成。

当同一时刻发生多个事件时，统一按照以下顺序执行：

1. 设备内部事件。
    - 当前生产计时完成 → 原子结算（扣输入 + 加输出）。
    - 清空计时。
    - 输入槽锁定或解除锁定。
    - 尝试启动新的生产计时（不扣原料）。
2. 输入物流事件。
    - 传送带向设备输入物品。
3. 输出物流事件。
    - 输出槽向传送带输出物品。

设备始终优先完成自身状态更新，再处理物流系统。
