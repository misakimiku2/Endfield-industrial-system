# Phase 2 — 工厂生产系统 实施计划

> **目标**: 传送带能跑物品、机器能根据配方生产、物品从传送带进入机器、产物从机器输出到传送带
> **周期**: 3 周（按单人+AI 节奏估算）
> **起点**: Phase 1 已完成（ECS+渲染+设备放置+相机控制+速度调节）
> **设计依赖**: A5（仿真规范）、A8（生产系统规范）、A9（物流系统规范）

---

## Phase 2 的核心链路

验证第一条自动化产线跑通：

```
仓库取货口(预配源矿×50)
    ↓ 输出轮询
传送带(直带 × 4 段)
    ↓ 物品进入设备端口
精炼炉 输入槽(接收源矿)
    ↓ 匹配配方 → 启动计时(不扣原料)
生产计时(2秒 → 计时完成 → 原子结算：扣源矿+产晶体外壳)
    ↓ 产物放入输出槽
精炼炉 输出端口
    ↓ 传送带接收
传送带(直带 × 2 段)
    ↓ 物品进入设备端口
仓库存货口(接收成品)
```

## T2.0 — 传送带创建系统

### 目标
实现从设备输出端发起的传送带绘制：创建、延申、截断，以及方向约束和防穿模检查。

> **设计依据**: A9 §6（传送带创建与编辑系统）。本任务是 Phase 2 的前置基础——后续所有传送带相关任务（T2.1 物品移动、T2.2 跨段传输）都依赖玩家能先创建出传送带。

### 需求

**创建起点（§6.1）**
- 选中设备 → 设备输出端口高亮
- 点击输出端口 Cell → 进入传送带绘制模式

**延申创建（§6.3）**
- 鼠标移动时显示半透明预览段，吸附网格
- 预览段根据鼠标移动方向自动判断朝向
- 连续点击可链式延申多段，新段继承父链 `chainId`
- **支持转弯形成 L 形链**：如 →→→ 后可延申为 →→→↑↑，每段独立记录 direction

**截断创建（§6.4）**
- 点击已有传送带的中间段 → 物理切断原链，分裂为上游链 + 孤立下游链
- 在截断点垂直方向引出新分支链（新分支与上游链同属一条逻辑链）
- 截断时已有物品按规则分流：走过截断点的物品继续沿孤立下游链流到末端后停留；截断处及后方物品进入新分支
- **孤立下游链与原链完全断开**，不再接收任何物品

**合并创建（§6.4.1）**
- 延申链的末端恰好接到一条孤立传送带的起点段（不连设备的断头链）时，可合并为一条完整链
- 合并后两条链共享同一 `chainId`

**方向约束（§6.5）**
- 延申：禁止反向（逆流）；允许同向继续或垂直转弯
- 截断：仅允许垂直方向分叉；禁止顺/逆流
- 违反约束时预览段显示红色，点击无效

**防穿模（§6.6）**
- 创建前检查目标 Cell 是否被设备占用
- 若被普通设备（生产设备、分流器、汇流器、供电桩等）占用 → 创建失败，提示"传送带不能穿过设备"
- **物流桥例外**：目标 Cell 是物流桥时允许穿过（物流桥是合法交叉点）

**链管理（§6.2）**
- 每段是独立 ECS Entity，但同一次创建/延申的段共享 `chainId`
- 选中任意一段 → 高亮整条链
- 支持删除单段 / 删除整链

### 验收标准（你在浏览器看到的效果）

- **放置一个精炼炉** → 点击它 → 输出端口（顶部 3 格）高亮
- **点击某个输出端口** → 进入绘制模式，鼠标位置出现半透明传送带预览
- **移动鼠标向上** → 预览段朝上（↑）
- **左键点击** → 创建一段传送带，固定在网格上
- **继续移动+点击** → 链式延申出多段传送带
- **延申时转弯**（先 → 再 ↑）→ 形成 L 形链，整条链仍是一个整体
- **尝试反向点击**（往源头方向） → 预览变红，点击无效
- **在已有传送带中间点击** → 截断成功，原链分裂，垂直引出新分支
- **截断后**：已有物品继续流向孤立下游链末端后停留（断头）；孤立链与原链不再有物品交换
- **延申到一条孤立传送带的起点** → 合并成功，两条链变成一条
- **尝试把传送带画到另一个生产设备/分流器上** → 预览变红，提示"不能穿过设备"
- **画到物流桥上** → 允许穿过（不报错）
- **右键 / ESC** → 退出绘制模式
- **点击已放置的传送带** → 整条链高亮（证明 chainId 生效）
- **删除整链** → 所有相关段消失

### 预估工时
2~3 次会话（交互逻辑 + 链管理 + 截断/合并 + 边界情况较多）

## T2.1 — BeltSystem 基础：单段物品移动

### 目标
实现物品在一段传送带上的移动逻辑和动画。

### 需求
- 物品 progress 推进（每 Tick +0.025，跨一格需 40 Ticks / 2秒）
- Pointer 动画（空载时循环，有物品时隐藏）
- 物品/pointer 居中于传送带表面渲染

### 验收标准（你在浏览器看到的效果）
- AI 执行测试命令 → 一段传送带出现在画布上，上面有物品
- **物品沿传送带方向匀速移动**（从一端走向另一端）
- **当物品走到尽头** → 停在段尾
- **画面没有物品时** → 黄色箭头（pointer）沿传送带循环移动
- 放大/缩小 → 物品和 pointer 位置正确

### 预估工时
1 次会话

## T2.2 — BeltSystem 扩展：跨段传输与堵塞

### 目标
实现物品从一段传送带传到下一段，以及堵塞逆流传播。

### 需求
- 段尾检测：progress ≥ 1.0 时检查相邻 Cell 是否有传送带
- 有 → 物品移到下一段重新走；无 → 停在段尾
- 下游段满 → 上游也停；下游疏通 → 上游恢复

### 验收标准（你在浏览器看到的效果）
- AI 执行测试命令 → 两段相连的传送带出现，上面有物品
- **物品走到第一段尽头** → **自动进入第二段**，继续前进
- **物品走完第二段到头**（无连接）→ 停在末端
- AI 执行"堵满"测试 → 下游堵住时，上游的物品也停下来
- AI 执行"疏通"测试 → 下游有空间后，上游物品恢复前进

### 预估工时
1 次会话

## T2.6 — 传送带 → 设备输入对接

### 目标
实现传送带末端物品进入设备输入槽的逻辑。

### 需求
- 传送带物品走到尽头 → 检查相邻 Cell 是否有设备输入端口
- 有且存在可接受的输入槽（空槽或锁定同类型且未满）→ 物品消失，输入槽 count + 1
- 输入槽满 → 物品停在传送带上

### 验收标准（你在浏览器看到的效果）
- AI 执行测试命令 → 一段传送带连接一个精炼炉
- **传送带上的物品走到尽头靠近精炼炉** → **物品消失**
- AI 在控制台检查 → 精炼炉输入槽 count 增加了
- AI 填满输入槽后 → 传送带上的物品在精炼炉门口停住

### 预估工时
1 次会话

## T2.8 — 输出缓冲区与状态机

### 目标
实现完整的设备状态机（idle → working → blocked）。

### 验收标准（你在浏览器看到的效果）
- AI 执行测试命令 → 一个精炼炉连接输入传送带和输出传送带
- **精炼炉空闲** → 状态为 idle
- **物品进入后开始生产** → 状态变为 working
- **输出堆满** → 状态变为 blocked
- **输出疏通后** → 恢复 working 或 idle
- 状态文字显示在设备上方（灰色=idle、绿色=working、红色=blocked）

### 预估工时
1 次会话

## T2.13 — 产线打通验证

### 目标
验证完整产线链路跑通 + 性能基准。

### 验收标准（你在浏览器看到的效果）
- **AI 执行"搭建标准测试产线"** → 自动生成：
  ```
  取货口(源矿) → 传送带×4 → 精炼炉 → 传送带×2 → 存货口
  ```
- **你看画面上的产线**：
  1. 取货口吐出源矿 → 传送带前进
  2. 源矿进入精炼炉 → 精炼炉变绿（working）
  3. 几秒后精炼炉吐出晶体外壳 → 传送带前进
  4. 晶体外壳到达存货口 → 消失
- **精炼炉旁边显示"输入: 满/50"和状态**
- **连续生产**：输入消耗一个 → 传送带补一个
- **产线中加入一段转角** → 物品顺利转弯
- **多设备并行**：3 台精炼炉同时工作
- **性能基准**：AI 一键生成 50 段传送带 + 10 台设备
  - 左上角 FPS ≥ 55

- **视觉基调**：浅灰背景（#E6E4E4）+ 网格线（#D6D4D4）+ 四角暗角 + 屏边渐隐透明

- 从取货口配置"产出源矿" → 传送带运输 → 精炼炉生产 → 传送带运输 → 存货口消失
- 精炼炉显示状态（working 绿色、blocked 红色）和缓冲区数量
- 传送带上的物品和 pointer 可见
- 支持转角传送带（4 方向）
- 左上角 FPS ≥ 55

## 关于测试效率

你描述的问题我非常理解——"修改→手动搭建→观察→描述症状→再修"这个循环确实很痛苦。解决方案是一个**测试场景速建系统**：

### 工作原理

Phase 2 开始时，AI 先创建一条特殊的**测试命令**，你只需要输入一条指令，比如：

```
/test 产线1
```

AI 会在游戏里**自动搭建**一套完整的测试产线，不需要你手动放任何设备。

### 预置测试场景

| 命令 | 自动搭建的内容 | 测试目的 |
|------|---------------|----------|
| `/test belt_create` | 一个精炼炉 + 已放置的几段传送带链 | 传送带创建/延申/截断交互 |
| `/test belt_single` | 一段传送带 + 一个物品 | 单段移动/pointer |
| `/test belt_chain` | 三段相连传送带 + 物品 | 跨段传输/堵塞 |
| `/test belt_corner` | 转角 + 两侧直带 + 物品 | 转角路径 |
| `/test furnace_basic` | 取货口→传送带→精炼炉→存货口 | 产线基础链路 |
| `/test furnace_3in` | 3 个取货口→3 条传送带→精炼炉→存货口 | 3 入轮询 |
| `/test furnace_3out` | 取货口→精炼炉→3 条传送带→3 个存货口 | 3 出轮询 |
| `/test full_line` | 完整的带转角的标准产线 | 全链路验证 |
| `/test perf_50` | 随机放置 50 段传送带 + 10 台设备 | 性能基准 |

### 你的测试流程

```
AI 修改代码 → 
你输入 /test furnace_basic → 
游戏自动生成产线 → 
你观察画布上的效果 → 
你觉得有问题 → 
描述给 AI → 
AI 修复 → 
你再次输入 /test furnace_basic →
确认问题已修复
```

**全程不需要你手动放任何一个设备。** 每次测试的产线配置完全一致，不会因为手抖放歪而影响判断。
